**Goal:** 크롤링 가이드의 데이터 지도(보기 `map.html` + 원문 `크롤링-가이드.md`)를 origin/main 코드 실체대로 재정의하고(로그인·위치 데이터종류별·왜 설명·신규소싱처·개선예정 병기), 신규 소싱처 추가용 성능 우선순위 판정 래더를 신설한다. 선행으로 40 URL 라이브 검증을 수행해 정답표를 산출한다.
