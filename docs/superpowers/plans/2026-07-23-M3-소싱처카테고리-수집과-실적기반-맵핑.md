# M3 소싱처 카테고리 수집 + 실적 기반 맵핑 자동 채움 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** ①크롤이 상품 카테고리 경로(빵부스러기)를 함께 수집해 `source_categories` 를 채우고, ②이미 마켓에 올린 상품에서 그때 고른 카테고리를 되받아와, ③둘을 조인해 `category_map` 을 **추측이 아닌 실적**으로 자동 채운다.

**Architecture:** 8개 소싱처 중 **6개는 추출이 서버(`crawlers/*.py::parse_html`)에 있어 서버 배포만으로 커버**되고, 무신사·롯데온 2개만 확장 수정이 필요하다. `CrawlResult` 에 필드 하나를 더하면 `asdict` → JSON → 확장 → `crawl-result` 로 자동 왕복한다. 마켓 회수는 기존 상품조회 함수가 **이미 받아오고 버리는 dict 값**을 꺼내 쓴다.

**Tech Stack:** 기존 그대로 (Flask·SQLAlchemy create_all/migrations·pytest cwd=`프로그램/_시스템`).

**스펙:** `docs/superpowers/specs/2026-07-22-더망고식-URL멀티마켓등록-카테고리맵핑-design.md` §B·§C
**베이스:** `origin/main`(M1·M2 머지 완료분). 워크트리는 새로 팔 것.

## 선결 결정 (M2 리뷰가 남긴 미확정 — 여기서 못 박는다)

**`SourceCategory.source_id` = 크롤이 쓰는 소싱처 문자열 키**(`SourceProduct.site` 와 동일 값: `musinsa`·`ssf`·`ssg`·`lemouton`·`lotteon`·`ss_lemouton`·`hmall`·`lotteimall`).
근거: 크롤 결과가 그 값을 그대로 들고 오고, `source_categories.source_id` 가 `String(40)` 이며, `SourceRegistry` 의 정수 id·한글 name 은 화면 표시용이라 크롤 경로와 맞지 않는다. **Task 1 에서 모델 주석을 이 결정으로 고친다**(주석과 실제가 어긋난 채 두면 맵핑표가 조회 안 되는 값으로 찬다).

## 사전 지식

1. 크롤 실행 주체 = **로컬 크롬 확장**(서버 크롤은 `server_crawl_gate.py` 로 기본 OFF). 하지만 **추출 로직은 6/8 소싱처가 서버 `parse_html`** 에 있다.
2. 확장→서버 신규 필드는 `background.js` 의 `BENEFIT_PASSTHROUGH` 화이트리스트를 통과해야 한다(없으면 조용히 유실). `pickBenefits` 는 빈 값(`''`/null)을 드롭 — 빈 빵부스러기는 전송 안 되고 서버 기존값이 보존된다(무스톰프, 의도된 동작).
3. 확장 버전은 `manifest.json` 과 `background.js` 상수 **둘 다** 올려야 한다(상습 불일치 이력).
4. 신규 컬럼(기존 테이블)은 `shared/db.py::_apply_lightweight_migrations` 의 `migrations` 리스트, 신규 테이블은 `create_all`.
5. pytest 는 경로 지정 필수. **git stash 금지.** 기존 실패 5건(test_send_tab 2·test_speed_settings 3)은 origin/main 기준선.

```python
# lemouton/registration/source_category_ingest.py
"""소싱처 카테고리 사전(source_categories) 적재 — 크롤이 본 경로를 축적한다.

크롤 한 번에 상품 하나의 경로가 하나 들어온다. 처음 보는 경로면 행을 만들고,
이미 있으면 product_count 만 올린다(그 경로로 몇 개나 크롤됐는지가 맵핑 우선순위 근거).
빈 경로는 저장하지 않는다 — 파싱 실패를 '카테고리 없음'으로 둔갑시키지 않기 위해서다.
"""
from __future__ import annotations

from lemouton.registration.models import SourceCategory


def normalize_path(raw):
    """'  신발 > 스니커즈 ' → '신발>스니커즈'. 빈 조각 제거. 못 쓸 값이면 ''."""
    parts = [p.strip() for p in str(raw or '').split('>')]
    return '>'.join([p for p in parts if p])


def ingest_path(session, source_id, raw_path, now):
    """반환 True=새 경로 추가 / False=기존 갱신 또는 무시. commit 은 호출자 몫."""
    path = normalize_path(raw_path)
    if not path or not source_id:
        return False
    row = (session.query(SourceCategory)
           .filter_by(source_id=str(source_id), path=path).first())
    if row is None:
        parts = path.split('>')
        session.add(SourceCategory(
            source_id=str(source_id), path=path, leaf_name=parts[-1],
            depth=len(parts), product_count=1, first_seen_at=now, last_seen_at=now))
        return True
    row.product_count = (row.product_count or 0) + 1
    row.last_seen_at = now
    return False
```
