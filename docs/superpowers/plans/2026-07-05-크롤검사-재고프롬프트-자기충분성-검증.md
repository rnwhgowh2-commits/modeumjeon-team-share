# 「크롤링 검사」 재고 프롬프트 자기충분성 검증 플랜

> **For agentic workers:** 이 플랜은 코드 구현 플랜이 아니라 **검증(도그푸딩) 실험 프로토콜**이다. 각 단계는 checkbox 로 추적한다. 실행 원칙 = 오염 없는 리트머스지: 테스트 서브에이전트에게는 **프롬프트 원문 + 대상 한 줄**만 준다. 메인 세션의 기억·과거 playbook 으로 구멍을 미리 메우지 않는다.

**Goal:** 「크롤링 검사」가 만드는 재고 정합성 프롬프트 하나만으로, 기억 없는 새 Claude 세션이 르무통_메이트 재고 검사를 막힘 없이·정확히 끝낼 수 있는지 검증하고, 못 하면 자기충분해질 때까지 프롬프트를 보강한다.

**Architecture:** (1) 정답지 확보 → (2) 깨끗한 서브에이전트에 프롬프트만 투입 → (3) 마찰 로그로 구멍 식별 → (4) 사용자와 보강 협의 → (5) 보강 후 새 깨끗한 서브에이전트로 재검증. 구멍이 0 될 때까지 (3)~(5) 반복.

**Tech Stack:** Agent 도구(general-purpose, 기억 없음) · git worktree(origin/main 분기, 보강 시) · 라이브 mou-m.com 매트릭스 API · Claude-in-Chrome/curl_cffi(서브에이전트가 자율 시도)
