## 판정 기준 (프롬프트 §4 준용)

- **대조 단위** = 색×사이즈 셀 × 소싱처 URL
- **판정** = 상태(있음/품절/확인불가) 기준. 정확 수량은 실시간 변동이라 비교 제외(메모리 방침, 안전).
- **OK** = 실브라우저 상태 == 프로그램 상태
- **NG** = 불일치 → 이중 태그:
  - **귀책**: U(URL측·대체상품·만료→사용자 정정) / P(프로그램측·크롤·저장·매칭→코드 수정)
  - **증상**: A 품절둔갑(실=품절, 프로그램=있음)★ / B 거짓품절 / C 999·센티넬둔갑 / D 미수집·확인불가 / E 수량불일치
