**Goal:** 스펙 [[2026-07-22-소싱처-표면노출가-혜택-최종매입가-design.md]]의 소싱처별 표면노출가 정의·혜택 목록·세트 규칙을 크롤러→저장→계산 엔진에 배선한다.

**Tech Stack:** Python(Flask·SQLAlchemy) + Chrome 확장(`background.js`) + pytest.

**작업 위치:** `_wt_benefit_fx` 워크트리(origin/main 기반) → 브랜치 `feature/benefit-fx-engine` → PR → main. 본체 워킹트리는 1,947커밋 뒤라 사용 금지.

def _has_review_row(session, source_id) -> bool:
    """이름에 '후기' 또는 '리뷰' 포함 행이 있으면 True — 이중차감 원천차단."""
    from .models import SourceBenefitTemplate as T
    rows = session.query(T).filter(T.source_id == source_id).all()
    return any(('후기' in (r.benefit_name or '')) or ('리뷰' in (r.benefit_name or ''))
               for r in rows)

def seed_review_rewards(session) -> int:
    from .models import SourceBenefitTemplate as T
    n = 0
    for key, name, amount in REVIEW_REWARD_SEED:
        sid = resolve_registry_id(session, key)
        if sid is None or _has_review_row(session, sid):
            continue
        session.add(T(source_id=sid, benefit_name=name, benefit_type='amount',
                      value=float(amount), category='정액', apply_mode='deduct',
                      enabled=True, sort_order=40))
        n += 1
    if n:
        session.commit()
    return n
