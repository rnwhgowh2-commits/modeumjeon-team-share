# (A) URL 자동 크롤 → 영수증 — 크롬확장 연결 (구현 계획)

> 2026-06-11. 사용자 선택 (A): ④ 신규 검증에서 **URL만 넣고 "검증"** 누르면 크롬확장이 자동 크롤 → 영수증까지 한 번에.
> 배경: 무신사는 로그인 브라우저/확장만 크롤 가능(서버 직접 X). 현재 위 "검증"은 워커 큐로 enqueue만 하고 워커 없어 "대기 중" 멈춤.

---

## 현재 구조 (조사 완료)

- 확장: `프로그램/_시스템/extension/moum-crawler/`
  - `background.js` (service worker): `chrome.runtime.onMessage` 로 `type:"crawl"` 받으면 → background 탭으로 URL 열고 → `EXTRACTORS[source_key]`(musinsaExtractor/lotteonExtractor) 페이지 컨텍스트 실행 → 결과 수집 → 탭 닫음.
  - `content_mou.js`: **mou-m.com 에만** 주입. `data-moum-ext` 마커 심고 `window.postMessage({__moum:"page",type,payload,reqId})` ↔ `chrome.runtime` 브리지.
  - `manifest.json`: content_scripts matches = `https://www.mou-m.com/*` 만. host_permissions 에 무신사 등 포함.
- 서버: `gate-preview`(`sourcing_guide.py`) = 혜택 라인 → 영수증. `save-check` = 저장된 검증(2-C). 둘 다 배포됨.
- ④ detail.js: 위 "검증" = `enqueue_verify`(워커 대기). 아래 "키워드 게이트 검증" = 라인 직접 입력 → gate-preview.

## 해야 할 3가지

### 1. manifest.json — 가이드 서버 도달 가능하게
- `content_scripts[].matches` 에 라이브 가이드 오리진 추가: `"http://54.116.196.90/*"` (+ 도메인 쓰면 그 도메인). content_mou.js 가 거기서도 마커+브리지 동작하게.
- `host_permissions` 에도 동일 오리진 추가.
- ※ http+IP 오리진 매칭 — MV3에서 허용되나 확인. 안 되면 `externally_connectable` 로 대체.

### 2. background.js `musinsaExtractor` — 혜택 라인 추출 추가
- 현재 가격(회원가 등)만 뽑음. **혜택 문구 라인**(예: "등급 할인 불가", "상품 쿠폰", "구매 적립 / 선할인", "10% 추가 적립", "결제혜택")도 DOM에서 수집해 결과에 `benefit_lines: [...]` 추가.
- 추출 셀렉터: 무신사 혜택 영역 leaf 텍스트(이번 세션에서 라이브로 검증한 추출 로직 참고 — 혜택/적립/쿠폰/회원/등급 키워드 포함 leaf, 길이<40).
- `surface_price`(회원가) 도 함께 반환(영수증 base).

### 3. detail.js — "검증" 버튼을 확장 브리지로
- 위 "검증" 클릭 시:
  1. `document.documentElement.getAttribute("data-moum-ext")` 로 확장 설치 감지. 없으면 "모음전 크롤러 확장 설치/리로드 필요" 안내(설치 페이지 링크).
  2. `window.postMessage({__moum:"page", type:"crawl", payload:{sources:[{source_key:"musinsa", url}]}, reqId})` → `message` 이벤트로 `{__moum:"ext", reqId, ok, resp}` 수신.
  3. resp.results[0].benefit_lines + surface_price → 그대로 `gate-preview` 호출 → 영수증 렌더(기존 kwReceipt 재사용, 단 예제 .rc 디자인으로 통일 — 사용자 별도 요청).
  4. textarea(수동 라인)는 폴백으로 유지.
- 기존 enqueue_verify(워커) 경로는 확장 미설치 시 폴백 또는 제거 결정.

## 영수증 디자인 (사용자 추가 요청 — 같이 반영)
- 신규 검증 영수증을 **예제 `.rc` 디자인**(표면가→−선반영→베이스①→−최대적립→베이스②→최종 + ※주석)으로 통일 + **포함/제외 판정도 표시**(사용자 선택지 "나"). 좌측 스크린샷도 예제 `.exshot` 디자인.

## 무결성 / 테스트
- 확장 변경 후 **사용자가 chrome://extensions 에서 모음전 크롤러 리로드** 필요(언팩 확장). 안내 명시.
- 무신사 **로그인 상태**여야 회원가·혜택 읽힘.
- live-browser-verify: 라이브 ④에서 URL(예 musinsa 4046672) 넣고 "검증" → 자동 크롤 → 영수증 자동 표시 → 저장 → 우측 리스트. (이번 세션의 2-C 저장 흐름과 결합)
- 확장 미설치/로그인 안 됨/타임아웃 시 친절한 에러.
