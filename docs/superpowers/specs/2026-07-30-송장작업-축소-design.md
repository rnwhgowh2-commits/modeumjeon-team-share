## 1. 무엇을 바꾸는가 — 4단계 → 2덩어리

07-24에 만든 4단계(①더망고 ②걸러내기 ③전송 ④검산)를 사장님이 축소 요청하셨다.

**핵심 변화** — 더망고 엑셀을 안 쓴다. **택배사 엑셀 하나**로 옛 ①과 ③이 합쳐진다.

```
[맨 위] 🧾 배송흐름 감시   ← 항상. 별도 단계 아님(옛 ④가 여기로)
   ✅ 배송 이상 없음
   최근 7일 요약 표 — 날짜별 송장 입력 / 배송 중 / 배송 완료
   날짜를 누르면 그날 주문이 세 갈래로 펼쳐짐

[본 작업] ① 택배사 엑셀 올리기
             ↓ 주문번호로 맞춰봄
          ② 송장전송목록
             밑줄 탭 — 🔵발송 대상 / 🔴이중송장 / 🔴확인불가
             택배사 고르기(칩)
             발송 대상 표 — 송장번호 자동 입력됨
             [요약 띠] 확인 N · 다름 N · 대기 N   「문제만 보기」
             [전송 버튼 하나]   ← 옛 ③ 단계 없앰
```

### 확정된 선택 (시안 반복 결과)

| 항목 | 확정 | 시안 |
|---|---|---|
| 감시 표현 | **M1** — 초록 배너 + 최근 7일 요약 표 | v7 |
| 3분류 표시 | **밑줄 탭**(글자 아래 파란 줄) + 작은 점만 색 | v7·v8 |

| 전송 버튼 | 발송 대상 표 **바로 아래 하나** (별도 단계 없음) | v7 |
| 전송 결과 | **R4** — 요약 띠 + 표 칸 안 3상태 | v9 |

## 2. 배송흐름 감시 (M1)

### 2.1 평소 (문제 없음)

```
✅ 배송 이상 없음
   🧾 송장 넣고 24시간 넘게 안 움직인 주문이 없어요
   아래는 최근 7일 지켜본 요약이에요 (날짜를 누르면 그날 주문이 보여요)

   날짜        송장 입력   배송 중   배송 완료
   오늘 07-30      12        8         3
   어제 07-29      15       10         6
   ...
```

- 초록 배너(`#EAF7EF` / 테두리 `#A9DCBB`)
- 7일 표 — 숫자는 **오른쪽 자릿수 맞춤**, 날짜는 왼쪽

### 2.2 날짜 클릭 → 그날 상세

밑줄 탭 3개로 나눈다:

| 탭 | 뜻 | 점 색 |
|---|---|---|
| 송장 입력 | 그날 우리가 송장을 넣은 건 | 파랑 |
| 배송 중 | 그날 배송중으로 바뀐 건 | 노랑 |
| 배송 완료 | 그날 배송완료로 바뀐 건 | 초록 |

표 열: 시각 · 판매처 · 계정 · 상품명 · 오픈마켓 주문번호 · 운송장번호

### 2.3 문제 있을 때

노랑으로 바뀌고 「모아보기 →」가 나타난다. 목록은 기존 `flow-stall.json` 그대로.

### 2.4 데이터 원천

- 감시 판정 = 기존 `lemouton/markets/flow_stall.py` **그대로**(24시간·엑셀 무관)
- **7일 요약은 신규** — 적재분에서 날짜별로 센다:
  - 구현 = `lemouton/markets/flow_daily.py` · 창구 `/orders/flow-daily.json`
  - 기준 날짜는 **셋 다 마켓이 준 발송처리일**(`발송처리일`) 하나뿐이고, 그날의 `주문상태`로
    송장 입력 / 배송 중 / 배송 완료를 가른다
  - ★ 송장 원장 `invoice_ledger.captured_at` 은 **안 쓴다** — `onupdate` 라 조회할 때마다
    갱신돼 '처음 넣은 날'이 아니다(쓰면 전부 오늘로 몰린다)
  - ★ 기준 시각이 없으면 **세지 않는다.** 대신 「판정 못 함 N건」을 함께 돌려준다(조용한 실패 금지).
    발송처리일을 주는 마켓은 스마트스토어·롯데온·11번가 셋뿐 — 쿠팡·옥션·G마켓은 `unknown` 으로 샌다

## 3. 택배사 엑셀 → 3분류

### 3.1 분류 기준

| 분류 | 조건 | 점 |
|---|---|---|
| 🔵 발송 대상 | 엑셀의 주문번호가 우리 주문에 있고 + 그 주문에 송장 없음 | 파랑 |
| 🔴 이중송장 | 그 주문에 **이미 송장이 있음** | 빨강 |
| 🔴 확인불가 | 엑셀의 주문번호가 **우리 주문에 없음** | 빨강 |

**발송 대상에만** 엑셀의 운송장번호가 자동 입력된다(초록 + 「자동」 표시).

### 3.2 택배사 고르기

칩으로 한 번만 고른다. 마켓별 코드 변환은 프로그램이 한다.

**못 보내는 마켓이 있으면 그 행을 「보낼 수 없음」으로 표시하고 전송 건수에서 뺀다** — 조용히 실패시키지 않는다.

현재 커버리지(2026-07-30 실측·PR#520·#525):

| 택배사 | 쿠팡 | 스스 | 11번가 | 롯데온 | 옥션 | G마켓 |
|---|---|---|---|---|---|---|
| 로젠·CJ대한통운·한진·롯데 | O | O | O | O | O | O |
| 우체국택배 | O | O | **X** | O | O | O |

## 4. 전송 결과 (R4)

### 4.1 요약 띠 (표 위)

```
전송 4건 · 확인됨 2  번호 다름 1  확인 대기 1 — 「번호 다름」은 마켓 값이 진짜예요   [문제만 보기]
```

- 문제 0건이면 초록, 있으면 노랑
- **「문제만 보기」** = 다름·대기만 남기고 거른다

### 4.2 표 칸 안 3상태 — **기존 코드 그대로**

`orders/index.html:1244-1253` 이 이미 만든다. 새로 만들지 않는다.

| 표시 | 클래스 | 뜻 |
|---|---|---|
| `✓ 전송 505045353994` | `.inv-ok` 초록 | 마켓 재조회로 **확인된** 번호 |
| `⚠ 마켓 A` ~~`입력 B`~~ | `.inv-no` 빨강 + `<s>` | 오입력 포착 — 마켓이 진짜 |
| `✓ 전송 B · 마켓확인대기` | `.inv-ok` + `.inv-wait` 회색 | 전송은 성공, 되읽기만 아직 |

행 배경도 기존 `tr.r-sent`(초록) / `tr.r-bad`(빨강) 그대로.

### 4.3 되읽기는 이미 구현돼 있다

`invoice_send.read_registered_invoice()` → 라우트 `orders.py:1090-1113` → 응답 `market_invoice_no`.
**6마켓 전부 분기가 있다.** 새로 만들 것 없음.

⚠️ **11번가만 주의** — 구매확정으로 넘어가면 API가 송장을 영영 안 준다. 전송 직후는 읽힌다.
⚠️ **쿠팡 되읽기 경로가 지도와 다르다** — 별건으로 점검(작업 #6).

## 5. 같이 고치는 것 (시안에서 드러난 함정)

| # | 문제 | 조치 |
|---|---|---|
| A | `.o7` 이 「212px + 나머지」 2단 격자 — 그 안에 넣은 부품이 갇혀 잘린다 | 새 배치에선 `.o7.flat{display:block}` |
| B | 열 고정폭 합계가 본문 폭을 넘으면 잘린다 | 합계를 폭 안에 맞추고 `overflow-x:auto` |
| C | 업로드가 두 곳(위 + 전송 띠) | 전송 띠에서 「📄 엑셀 업로드」 제거 — 업로드는 한 곳 |
| D | 감시가 오른쪽 280px 칸이라 7일 표·상세가 안 들어간다 | 감시를 **맨 위 가로 띠**로. `.o7.ship` 은 2단(236px + 1fr) |
| E | 격자 자식이 여럿인데 한 자식만 `grid-row:1/99` 로 넘기면 **빈 행마다 gap 이 붙어** 칸이 2,398px 로 늘어난다 | 왼쪽을 `.wleft` 로 감싸 **자식을 둘로**. 실측 409px |
| F | 화면 `SENDABLE` 에 옥션·G마켓이 없어 **그 마켓 주문이 조용히 전송에서 빠졌다**(서버는 6마켓 다 지원) | 6마켓으로 맞추고, 서버 `SUPPORTED_SEND` 와 **같은지 검사하는 테스트** 추가 |
| G | 전송 성공이어도 마켓 값이 입력과 다르면 문제인데 행이 **초록**이었다 | `rowCls` 에서 불일치는 빨강(`r-bad`) |

## 7. 검증 기준

1. 택배사 엑셀 **한 번만** 올리면 3분류가 갈리고 발송 대상에 송장번호가 자동으로 찬다
2. 업로드 칸이 화면에 **하나뿐**이다
3. 전송 버튼이 발송 대상 표 **바로 아래 하나**다
4. 전송 뒤 요약 띠에 「확인 N · 다름 N · 대기 N」이 뜨고 「문제만 보기」가 걸러준다
5. 표 칸에 3상태가 기존 색·취소선 그대로 뜬다
6. 감시 배너에 최근 7일 요약이 뜨고, **날짜를 누르면** 송장입력/배송중/배송완료로 갈린다
7. 못 보내는 택배사·마켓 조합은 「보낼 수 없음」으로 **드러난다**(조용한 실패 없음)
8. **1920px 화면에서 표가 안 잘린다**
9. 라이브 URL에서 위 8가지를 실제로 확인한다
