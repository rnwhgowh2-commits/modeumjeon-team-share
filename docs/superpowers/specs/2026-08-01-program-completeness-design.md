## 4. 순서 — 「눈부터 뜨고 → 고친다」

세 가지 순서를 놓고 골랐다.

- A안 안전장치 → 돈 → 화면 → 구조 : 방어적이나 사장님이 결함을 계속 봐야 함
- B안 돈 먼저 : **안전장치 없이 돈 코드를 고치는 건 위험** (내 사고가 가격 계산에서 나면 손실)
- **C안 관측 장치만 먼저 깔고(코드 안 고침) → 고친다** ← 채택

**C안을 고른 근거는 이번 세션 자체다.** 감사기를 만들기 전에는 결함을 20,986곳으로
잘못 세고 있었다. 만들고 나서야 원인 40가지로 줄어 실제로 고칠 수 있었다.
돈 쪽도 같다 — **지금은 가격·재고가 틀렸는지 아무도 재고 있지 않다.**

## 5. 묶음 4개

### 묶음 1 — 눈 뜨기 (관측) · 1~2일

**1-1. 배포 게이트**
병합 전 테스트 484개 + `scripts/check_css_balanced.py` 통과해야 배포.

🔴 **먼저 할 일이 있다.** 이 저장소 테스트는 공유 SQLite(`data/lemouton.db`)를 오염시켜
실패 개수가 실행마다 널뛴다(22~51). 지금도 `tests/margin/test_order_export_settle_source.py`
2건은 **내 작업 전부터 실패** 중이다(작업 전 워크트리에서 3건 실패로 확인).
→ **고정 실패를 격리·정리한 뒤에 게이트를 건다.** 안 그러면 엉뚱한 이유로 배포가 막힌다.

**1-2. 돈·계정 감시기** — 디자인 감사기(`scripts/design_audit_live.py`)와 같은 방식
매일 자동으로 **실제 소싱처 URL·마켓 API 와 우리 저장값을 대조**하고 어긋나면 알린다.
- 가격 : 표면노출가·최종매입가가 실브라우저 값과 같은가
- 재고 : 있다고 표시한 게 실제로 있는가 (모르면 「확인 불가」인가)
- 전송 : 우리가 보낸 값과 마켓에 올라간 값이 같은가

### 묶음 2 — 돈·계정 위험 잡기 · 1~2주

감시기가 켜지면 어디가 틀렸는지 숫자로 나온다. 그걸 원인별로 잡는다.

**2-1. 「조용한 실패」 없애기.** 기록에 남은 원인 셋 — 데이터베이스 제약 없음 · 값의 출처가
갈라짐 · 빠져도 경고 없음. 방향은 **「모르면 모른다고 한다」**(폴백가·평균값 금지, 「확인 불가」).
이미 프로젝트 규칙이지만 코드가 다 따르는지는 **재봐야 안다.**

**2-2. 값의 출처를 하나로.** 같은 값이 여러 곳에 있으면 반드시 갈라진다
(이번 디자인 작업의 「전환 버튼 3벌」이 같은 병).

**2-3. 마켓에 나가기 전 마지막 관문.** 전송 직전에 실측과 한 번 더 대조하고 어긋나면 멈춘다.
계정 위험은 되돌릴 수 없으니 「보내고 확인」이 아니라 **「보내기 전에 막기」**.

**끝났다고 말할 수 있는 조건**: 감시기가 매일 0을 보고한다.

### 묶음 3 — 화면 가독성 마무리 · 3~5일

**3-1.** 시안용 파일(`_mockups/…`)을 감사 대상에서 뺀다 — 화면이 아니다.
남는 실제 화면 240~350곳을 원인별로 정리.

**3-2. 기존 타입 11,220곳** ← 이번에 새로 들어온 것. 결과를 미리 적어 둔다.
- **화면이 눈에 띄게 달라 보인다** (흐린 회색 글자가 진해짐)
- 고치고 나면 **기존 타입과 화이트 타입이 거의 같아진다** → 타입 4개를 유지할 이유가
  줄어들 수 있다. 그건 그때 사장님이 정한다.
- **「돌아갈 자리」 역할은 유지된다** — 색만 바뀌고 뼈대(왼쪽 사이드바)는 그대로.

**3-3. 브랜드 마크는 그대로.** 감사에서만 빼서 진짜 결함이 눈에 띄게 한다.

### 묶음 4 — 구조 부채 · 1주

**4-1. 뼈대 4개 → 1개.** 이 부류 결함이 구조적으로 사라진다.

**4-2. 검사 방식 바꾸기.** 지금 테스트는 「이 글자가 이 글자와 같은가」를 본다.
그래서 정당한 수정에 계속 깨지면서(이번에 10개쯤 고쳐 씀) **정작 진짜 고장은 놓쳤다.**
→ **「무엇이 참이어야 하는가」**로 바꾼다 (CSS 로서 말이 되는가 · 대비가 기준을 넘는가 ·
되돌릴 통로가 있는가). 이번에 새로 쓴 `tests/design/test_css_balanced.py` 가 그 형태다.
