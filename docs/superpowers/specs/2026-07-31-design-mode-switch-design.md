# 디자인 4모드 전환 — 설계

> 작성 2026-07-31 · 승인 완료
> 관련 규칙: `docs/디자인-규칙.md` · `프로그램/_시스템/webapp/static/tokens.css`

## 왜 만드나

새 디자인(애플 규칙)을 전 화면에 입히되, **문제가 생기면 즉시 현재 디자인으로 돌아갈 수 있어야** 한다.
현재 디자인은 안전망으로 남기고, 새 디자인이 자리를 잡으면 그때 지운다.

## 무엇을 만드나

디자인 모드 4개 중 하나를 **사람마다** 골라 쓸 수 있게 한다.

| 화면에 보일 이름 | 내부 값 | 정체 |
|---|---|---|
| **현재** | `current` | 지금 그대로. **기본값** |
| **검정 한 판** | `mono` | 시안 1 — 화면 전체가 검정 하나 |
| **검정 3단** | `layer` | 시안 4 — 바탕 → 카드 → 표 머리가 한 단계씩 밝게 |
| **밝은 카드** | `light` | 시안 9 — 흰 바탕 + 가로 카드 요약 |

---

## 안전망 구조 — 설계의 핵심

> **「현재」를 고르면 새 CSS 가 한 줄도 관여하지 않는다.**

- `current` 일 때 화면 바깥 상자에 `ds` 표시를 **붙이지 않는다** → `tokens.css` 의 모든 색 규칙이 잠들고 기존 CSS 만 동작
- 신규 3모드일 때만 `ds` + 모드 표시를 붙인다
- 새 디자인이 아무리 망가져도 `current` 로 돌리면 **원래 화면 그대로**

이 성질 때문에 「전 화면 한 번에」가 가능하다. 되돌릴 수 없다면 화면 하나씩 가야 했다.

## 저장

- `users` 테이블에 `design_mode VARCHAR(16) NOT NULL DEFAULT 'current'` 추가
- 이 저장소에 Alembic 이 없으므로 **`shared/db.py:_apply_lightweight_migrations()` 의 `migrations` 목록에 한 줄 추가** (프로젝트 CLAUDE.md 규정)
- **서버가 화면을 그릴 때 `<html data-design="...">` 로 바로 넣는다** — 브라우저가 나중에 바꾸면 화면이 한 번 깜빡인다(FOUC)
- 로그인 전 화면은 `current` 고정

### 기존 테마 장치와의 관계
`base.html` 에 이미 `localStorage.theme || 'toss'` → `data-theme` 장치가 있다(`stripe` 테마용).
**건드리지 않는다.** `data-design` 은 별도 축으로 추가한다. 두 축은 서로 간섭하지 않는다.

## 전환하는 곳 — 두 군데

1. **설정 화면 「디자인」** — 4개를 미리보기와 함께 고름
2. **상단 오른쪽 작은 버튼** — 문제가 생겼을 때 **즉시 `current` 로** 돌아올 수 있어야 하므로 깊이 숨기지 않는다

## 기능 무손실 보장

**요구사항: 기능은 하나도 빠짐없이 그대로 동작해야 한다.**

### 실측한 위험

| 위험 | 실측 | 처리 |
|---|---:|---|
| JS 가 색 문자열을 **비교**(`색 === '#DC2626'`) | **0곳** | 위험 없음 |
| JS 가 현재 색을 **읽음**(`getComputedStyle().color`) | 37곳 / **9개 파일** | **자동 치환 제외**, 사람이 확인 |
| JS 가 색을 직접 넣음 | 150곳 / 26개 파일 | **손대지 않음** |

가장 위험한 「색 비교」 패턴이 **0곳**이라 치환이 기능을 깨뜨릴 확률이 낮다.

### 치환이 건드리지 않는 것
- `class` 이름 · `id` · `data-` 속성 · JS 선택자 — **한 글자도 안 건드린다**
- Jinja 문법(`{{ }}` `{% %}`) 안쪽
- JS 문자열 리터럴 안의 색

## 검증

1. **화면별 전/후 자동 캡처 비교** — 162개를 눈으로 다 볼 필요가 없게 한다
2. **기존 테스트 실행** — ⚠️ `origin/main` 에 원래 실패하는 테스트가 있으므로 **바꾸기 전 상태와 대조**해 새로 깨진 것만 본다. `pytest` 를 인자 없이 돌리지 않는다
3. **주요 화면 실제 조작** — 조회 · 필터 · 정렬 · 송장 입력 · 엑셀 내보내기
4. **규칙 검사기** — `check_design_tokens.py` 로 위반이 줄었는지 확인
