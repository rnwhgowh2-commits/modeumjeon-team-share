## 1. 불변 공식 (변경 없음 — 현행 엔진 그대로)

```
최종매입가 = 표면노출가 − 혜택(fx)
  · 정액(원) 먼저 → 정률(%)은 직전 잔액에 순차 곱셈 차감
  · 경로(결제 택1 × 경유 택1) 전부 계산해 가장 싼 경로 자동 채택
  · 마지막 백원 단위 버림
```

## 2. 표면노출가 결정 원칙 (사장님 위임 → Claude 결정 → 승인)

> **"조작 없이 크롤할 수 있는 가격 중, 무엇이 포함됐는지 정확히 아는 가격"**

1. 개인화 가격(등급·오너스 섞임) 원칙 금지. **예외 = 사장님 명시 확정**(스스 나의할인가·롯데온 최대혜택가 — §3).
2. 카드·결제 혜택이 선반영된 가격 금지 (결제수단은 우리가 고르는 축). **예외 = 롯데온**(§3-5, 사이트가 카드 조건 충족을 자동 반영해 주는 가치가 더 큼 — 대신 이중차감 방지 규칙 필수).
3. 모두에게 동일한 할인(즉시할인·자동쿠폰)이 포함된 가격은 허용 — 그 항목은 **선반영으로 표시하고 fx 차감에서 제외** (이중차감 방지).
4. 못 지키면 조작(토글 OFF 등)해서라도 깨끗한 가격을 얻는다 (무신사 방식).

## 3. 소싱처별 확정표

공통: 현대카드 2.73%(결제 택1 기본 후보) · 네이버페이 1%(결제와 **동시 적용**, 택1 아님) · 리뷰적립(§5).
"선반영" = 표면노출가에 이미 포함 → fx 차감 금지(이중차감 방지). 값이 %·원으로 상품마다 다른 항목은 **크롤값** 사용(없으면 0 = 안 깎음).

### 3-1. 르무통 공홈
- 표면노출가: **판매가격** (기본할인 반영된 노출 판매가)
- 선반영: 기본할인
- fx: 현대카드 2.73% · N페이 1% · 리뷰 포토 5,000원
- 등급·쿠폰·적립 없음

### 3-2. 스마트스토어(스스)
- 표면노출가: **나의할인가** (상품쿠폰 「쿠폰받기」 자동 ON 포함가)
- 선반영: 상품쿠폰
- fx: 구매적립 기본 1% · 현대카드 2.73% · N페이 1% · 리뷰(§5 — 크롤 4항목, 르무통 상품 = 포토 3,000+한달포토 2,000)
- 크롤 위치: 적립 > 최대 적립 포인트 X원 클릭 > 구매적립·리뷰적립 항목

### 3-3. 무신사
- 표면노출가: **API `goodsPrice.salePrice` 직읽기** (할인항목 토글 전부 OFF 기준값)
  - ★「적립금 사용」 사이트 기본 ON → 끈 상태 기준 / ★「쿠폰적용가」 뜨면 특별쿠폰 선반영 주의
  - 적립금 선할인 → 라디오 「구매 적립」 선택 / 결제수단 즉시할인 → 「적용 안함」 선택
- 선반영: 없음
- fx: 등급할인(LV별 상시%, 로그인 크롤) · 상품쿠폰(쿠폰별 키워드 게이트 — 1회성·LV 지급 쿠폰 제외) · 구매적립(라디오=구매적립 택, 적립금 사용과 중복 방지) · 구매 추가적립(특수 케이스) · 리뷰 텍스트 500원
- **결제 택1: 무신사머니 적립 vs 현대카드 2.73% 중 큰 쪽 자동 선택** (무신사머니는 금액 크롤 — 블랙다이아 기준 4%. 종전 "머니 있으면 무조건 머니"에서 변경)
- 제외: 무신사페이·타사페이 1회성 카드사 추가할인 → 추가수익 처리

### 3-4. SSF
- 표면노출가: **`em.price`** (비로그인 "최대" 표기가 아닌 할인가, 조작 없음)
- 선반영: 상품할인(시즌 등)
- fx: 다운로드 쿠폰(「쿠폰다운」 버튼 — 표면 미반영이므로 차감) · 기프트포인트 10%(코드 주입) · 멤버십포인트 0.5~5%(크롤 환산) · 현대카드 2.73% · N페이 1% · 리뷰 텍스트 200원
- 제외: 카드사 1회성 추가할인 → 추가수익 / N쇼핑 없음(❌)

### 3-5. 롯데온 ★베이스 변경 (2026-07-22 사장님 확정)
- 표면노출가: **「최대 할인혜택 적용하기」 체크 후 나의 혜택가** (예: 81,320 → 75,630)
  - 이유: 카드사별 즉시할인의 조건 충족(결제금액 이상 등)을 **사이트가 상품별로 자동 반영** — "자세히" 조건 파악 불필요
- 선반영: 스토어 즉시할인 + **최적 카드 즉시할인**(예: 카카오페이 카드 7%)
- fx: 오너스 적립 0.5% · L.POINT 0.05% · N쇼핑 제휴할인(경유·정액) · OK캐시백 1.1%×0.9 · 리뷰 텍스트 50원
- **카드 경로 규칙 (핵심 — 이중차감 방지 + 겹침 반영)**:
  | 상황 | 계산 |
  |---|---|
  | 선반영 최적 카드 = **현대카드** | 최대혜택가에서 **추가로 현대카드 2.73% 차감** (사이트 즉시할인 + 카드 자체 2.73% 둘 다 받음) |
  | 선반영 최적 카드 = **다른 카드** | 그 카드 결제 가정 → 2.73%·N페이 1% 차감 안 함 |
  | 카드 즉시할인 **없는 상품** | 현대카드 2.73% + N페이 1% 차감 |
  - 엔진은 경로 열거로 자동 정밀화: 카드 즉시할인 목록(카드명+금액 크롤)을 받아
    `각 카드 c: 즉시할인(c) + (현대카드면 +2.73%)` vs `N페이 경로: 2.73%+1% (즉시할인 포기)` 중 최저가 채택.
    (예: 타 카드 즉시할인이 2%뿐이면 현대카드 2.73% 경로가 자동 승리)
  - **보유 카드 가드 (사장님 확정)**: 카드 마스터(`PurchaseCard` 17종)에 **있는 카드만** 즉시할인 후보로 인정.
    없는 카드가 최적으로 잡힌 최대혜택가는 그 할인분을 **되돌려서(가산)** 계산 — 없는 카드 할인으로 매입가 과소(마진 과대 착각) 방지.
- 제외/보류: 토스페이 2.5%(기간성 불확실) · L.PAY 제휴할인(횟수 미상) · L.PAY 충전 2%(현대카드보다 낮음)

### 3-6. SSG
- 표면노출가: **`bestAmt`(최적가)** (조작 없음)
- 선반영: 즉시할인 + SSG MONEY 즉시할인(패턴 A/C)
- fx: SSG MONEY 적립 n%(현행 2분기 유지 — ①상시 / ②충전결제 rate≥3%만) · 상품쿠폰(기간한정) · N쇼핑 쿠폰버튼 5~10%(경유·표면 미반영) · **청구할인(카드혜택가 정률·크롤) + 제휴할인 — 둘 다 동시 적용 가정(사장님 확정, 제휴 안 되면 추후 제거)** · OK캐시백 2.0%×**1.0**(전액 예외) · 현대카드 2.73% · 리뷰 텍스트 50원
- **N페이 1% 적용 안 됨** (사장님 확정)
- 제외: SSG MONEY 충전적립 1.5%(현대카드보다 낮음)

### 3-7. Hmall (현대H몰)
- 표면노출가: **`itemPtc.bbprc`(깜짝할인가)** — 카드할인 미포함 ✅
  - ⚠️ 크롤 함정: 옵션루프 `sellPrc` 우선하면 정가로 둔갑 (엑셀·크롤가이드 공통 경고)
- 선반영: 깜짝할인
- fx: VIP 라운지 할인(로그인·상품별 크롤) · 상품쿠폰(기간한정) · H.Point 적립 0.1~1%(이벤트 상품 5% 有 — 크롤값) · N쇼핑 4~10%(경유) · OK캐시백 **2.7%×0.9 (보류 해제 확정)** · 현대카드 2.73% · N페이 1% · 리뷰 텍스트 100원
- **카드 즉시할인 경로 (2026-07-22 사장님 확정 "카드경로 있으면 싼걸로")**: 상품페이지 「즉시 할인」 카드 목록(카드명·%·결과가격 — 예: KB국민 5%→113,905·삼성 5%→113,905) 크롤 → 롯데온식 경로 열거 `각 카드 c: 즉시할인(c)` vs `현대카드 2.73%+N페이 1%` 최저가 채택 + **보유 카드 가드(PurchaseCard 마스터에 있는 카드만)**. bbprc 베이스는 카드 미포함이므로 이중차감 없음.
- 보류: H포인트페이 카드사 추가할인(1일 한도 有)

### 3-8. 롯데아이몰 ★베이스 변경
- 표면노출가: **`benefitPrc` + 카드금액 = 카드 미적용가** (예: 116,900 사용)
  - ★「최대할인가」 금지 — 카드 청구할인 선반영이라 (예: 108,720 금지)
- 선반영: 상품쿠폰(기본 ON, benefitPrc에 포함)
- fx: **카드 청구할인(카드혜택가 정률 — fx로 분리 차감)** · L.CLUB 적립 0.5%(가입 시) · N쇼핑 ~15%(경유·상품별) · OK캐시백 **2.5%×0.9 (확정 — 엑셀 M열 근거, 시드표의 '롯데홈쇼핑 매핑 미확인' 해소)** · 현대카드 2.73% · 리뷰 텍스트 100원
- 보류: L.PAY 카드사 추가할인(1일 한도 有)

### 3-9. ABC
- **이번 범위 제외** (신규 소싱처 — 추후 별도 작업). 엑셀 N열 자리만 유지.

## 4. 세트 규칙 (엔진 경로 모델)

1. **경유 택1**: {일반 / N쇼핑 경유 / OK캐시백 경유}
   - N쇼핑 경유 ⟹ OK캐시백 OFF (현행 `naver_via ⟹ cashback off` 그대로)
   - OK캐시백 경유 ⟹ N쇼핑 혜택 OFF, **현대카드 2.73%는 유지** (자사페이에 카드 연동 — 사장님 확정)
2. **결제 택1**: 현대카드 2.73% 기본. 무신사만 {무신사머니 vs 현대카드} 경쟁. 롯데온은 §3-5 카드 경로 규칙.
3. **N페이 1%**: 결제 택1과 **동시 적용** (택1 그룹에 넣지 않음 — 현행 `_is_payment` 네이버 제외 설계 유지). SSG·롯데아이몰 미적용, 롯데온은 §3-5 조건부.
4. 경로 전부 계산 → 최저가 자동 채택 (현행 tagged 방식). **1회성/이벤트성 혜택은 경로에 넣지 않고 추가수익 처리.**

## 6. OK캐시백 (base_ratio — 부가세 계수)

| 소싱처 | 적립율 | base_ratio | 상태 |
|---|---|---|---|
| SSG | 2.0% | **1.0** (전액 예외) | 기시드 ✅ |
| 롯데온 | 1.1% | 0.9 | 기시드 ✅ |
| Hmall | 2.7% | 0.9 | **신규 시드 (보류 해제 확정)** |
