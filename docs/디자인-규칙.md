## 왜 만들었나 — 실측 진단 (2026-07-30)

템플릿 **162개** 전수 조사 결과입니다.

| 항목 | 당시 | 규칙 |
|---|---:|---:|
| 글자 크기 종류 | **46종** | 7종 |
| 색(hex) 종류 | **775종** | 17종 |
| 안쪽 여백 종류 | **404종** | 7종 |
| 둥근 모서리 종류 | **23종** | 4종 |
| `style=""` 직접 지정 | **6,116곳** | 줄여 나감 |

**근본 원인은 변수를 안 써서가 아닙니다.** `var(--…)` 는 이미 2,443곳에서 쓰고 있었습니다.
문제는 **같은 이름을 화면마다 다시 정의**한 것입니다.

- `--sub` → `#8B95A1`(5개 파일) vs `#6B7684`(5개 파일) — 정확히 반반으로 갈림
- `--ink` `--line` `--line2` → 각각 12개 · 12개 · 9개 파일에서 따로 정의
- `--red` 4가지 값, `--green` 4가지 값

이름은 같은데 값이 달라, 한 곳을 고쳐도 다른 화면은 안 바뀝니다. 이것이 "디자인이 불규칙해지는" 구조입니다.

## 1. 글자 — 7단

가장 많이 쓰이던 값을 그대로 승격시켰습니다. 새로 만든 게 아니라 **정리**입니다.

| 이름 | 크기 | 굵기 | 쓰는 곳 |
|---|---:|---:|---|
| `--fs-배지` | 11px | 600 | 상태 배지, 단위(원·개·%) |
| `--fs-표` | 12px | 400·600 | 표 안 글씨 — **당시 1,165곳으로 최다** |
| `--fs-본문` | 14px | 400 | 설명문, 입력칸 — 1,054곳 |
| `--fs-카드제목` | 17px | 600 | 카드 머리 |
| `--fs-섹션제목` | 22px | 700 | 구역 머리 |
| `--fs-화면제목` | 32px | 700 | 페이지 머리 |
| `--fs-요약숫자` | 64px | 700 | 대표 숫자 하나 (마진 합계 등) |

**중간값 금지** — 12.5 · 13 · 13.5 · 11.5 처럼 사이 값을 새로 만들지 않습니다.

## 2. 굵기 — 3단
`400` 본문 / `600` 강조 / `700` 제목. 그 외(300·500·800) 금지.

## 3. 자간 — 3단
글자가 클수록 좁힙니다(애플 방식).
`--ls-큰글씨` −0.03em / `--ls-제목` −0.015em / `--ls-본문` −0.005em

## 6. 색 — 애플 시스템 색만

애플이 공식 배포하는 색만 씁니다. 그 외 색은 금지입니다.

| 용도 | 값 | 변수 |
|---|---|---|
| 주 동작·링크 | `#007AFF` | `--primary` `--blue` |
| 정상·이익 | `#34C759` | `--green` `--색-정상` |
| 오류·손실 | `#FF3B30` | `--red` `--색-위험` |
| 주의·대기 | `#FF9500` | `--amber` `--색-주의` |
| 배송 진행 | `#5AC8FA` | `--상태-준비` |

회색 6단: `#F5F5F7` `#E8E8ED` `#D2D2D7` `#86868B` `#424245` `#1D1D1F`

### 의미는 절대 바꾸지 않습니다
빨강=손실 · 초록=이익 · 주황=주의 · 파랑=동작. 예쁘다고 바꾸면 금전 사고로 이어집니다.

### 주문 상태 배지 6계열
기존 12개 통일 상태와 1:1로 맞췄습니다.

| 계열 | 상태 |
|---|---|
| 회색 | 결제대기 · 결제완료 |
| 하늘 | 배송대기중 · 배송준비중 |
| 파랑 | 배송중 |
| 초록 | 배송완료 · 구매확정 |
| 주황 | 취소요청 · 반품요청 · 교환요청 |
| 빨강 | 취소완료 · 반품완료 · 교환완료 |

## 7. 정렬 — 데이터 종류로 정한다

| 데이터 | 정렬 |
|---|---|
| 숫자·금액·수량 | **오른쪽 + 자릿수 세로 정렬**. 단위(원·개·%)는 떼어 작게 |
| 이름·상품명·옵션 | 왼쪽 |
| 상태·배지 | 가운데 |
| `A → B` 비교칸 | **3칸** — 왼쪽값 우측정렬 │ 화살표 가운데 │ 오른쪽값 좌측정렬 |

비교칸을 셀 통째로 정렬하면 값 길이가 행마다 달라 **화살표가 들쭉날쭉**해집니다.

## 8. 다크 화면
- 순검정 배경은 구역 단위로만. 카드·표는 한 단계 밝게(그림자 대신 **밝기로 층**)
- 글자는 순백 금지 — `#F5F5F7`
- 선은 흰색 10% 투명

## 적용 방법

### 크기·여백·둥글기
`:root` 에 있으므로 어디서든 바로 씁니다.
```css
padding: var(--sp-5);
font-size: var(--fs-표);
border-radius: var(--r-카드);
```

### 색
화면 바깥 상자에 `class="ds"` 를 붙인 곳에만 적용됩니다.
```html
<section class="screen ds">   <!-- 밝은 화면 -->
<section class="screen ds ds-dark">   <!-- 어두운 화면 -->
```
기존 `--ink` `--sub` `--line` `--primary` 에 그대로 연결해 두었으므로,
**이미 있는 `var(--…)` 는 한 줄도 고칠 필요가 없습니다.**

화면 하나씩 옮길 수 있고, `ds` 글자만 지우면 즉시 되돌아갑니다.

## 금지 목록

| 하면 안 되는 것 | 대신 |
|---|---|
| `font-size:13px` | `var(--fs-표)` 또는 `var(--fs-본문)` |
| `padding:18px` | `var(--sp-4)` 또는 `var(--sp-5)` |
| `color:#3182F6` | `var(--primary)` |
| 화면 안에서 `--ink:` 다시 정의 | tokens.css 한 곳에서만 |
| `style="..."` 로 새 부품 만들기 | `.ds-카드` `.ds-배지` `.ds-알약` 사용 |
| 초록을 경고로 사용 | 경고는 반드시 주황 |
| 숫자를 가운데 정렬 | 숫자는 오른쪽 + 자릿수 정렬 |
