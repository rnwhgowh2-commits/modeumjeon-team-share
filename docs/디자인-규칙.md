# 디자인 규칙 — 모음전

> **계층**: 프로젝트 도메인 규칙
> **책임**: 화면에 보이는 모든 글꼴·크기·굵기·색·여백·정렬·배치·강조의 단일 진실 원천
> **실제 값**: `프로그램/_시스템/webapp/static/tokens.css` (이 문서와 항상 같아야 함)
> **검사**: `python 프로그램/_시스템/scripts/check_design_tokens.py`
> **근거**: apple.com/kr **3개 페이지 브라우저 실측** (2026-07-31)

---

## 0. 실측 방법 — 추측이 하나도 없습니다

브라우저에서 각 페이지의 **모든 요소의 계산된 스타일(computed style)** 을 읽어 집계했습니다.

| 잰 페이지 | 성격 | 왜 골랐나 |
|---|---|---|
| apple.com/kr | 브랜드·마케팅 | 애플의 기본 톤 |
| iPhone 17 Pro **구입하기** | 선택·폼 밀집 | **우리 프로그램과 가장 비슷** |
| iPhone 17 Pro **소개** | 검정 구역 | 어두운 화면 규칙 |

성격이 다르면 값도 다릅니다. 그래서 세 개를 나눠 쟀습니다.

## 1. 글꼴

**애플 실측**: 한국어 페이지 전체가 **`SF Pro KR` 한 가지**(151곳). 다른 글꼴이 섞이지 않습니다.

**우리 규칙**: **Pretendard 하나만.** SF Pro 는 애플 기기 전용 라이선스라 웹에 못 씁니다. Pretendard 는 SF Pro / Apple SD Gothic Neo 를 대체하려고 만들어진 글꼴이라 글자 폭·높이가 거의 같습니다.

- 숫자 전용 글꼴을 따로 쓰지 않습니다. `tabular-nums` 로 자릿수만 맞춥니다
- 화면에서 `font-family` 를 다시 지정하지 않습니다

## 2. 글자 크기 — 중요도 7등급

**애플 실측 크기**: 11 · 12 · 14 · 17 · 19 · 21 · 24 · 28 · 32 · 48 · 56

**페이지 성격별로 최다 크기가 다릅니다.**

| 페이지 | 최다 크기 |
|---|---|
| 홈(마케팅) | **12px** (84곳) |
| **구입하기(폼)** | **14px** (153곳) ← 우리와 가장 비슷 |
| 소개(마케팅) | **17px** (78곳) |

우리는 표가 본체라 **12px = 데이터, 14px = 본문**으로 둡니다.

| 등급 | 이름 | 크기 | 굵기 | 줄간격 | 쓰는 곳 |
|---:|---|---:|---:|---:|---|
| 0 | `--fs-배지` | **11px** | 600 | 1.33 | 배지 · 단위 · 법적 고지 |
| 1 | `--fs-표` | **12px** | 400·600 | 1.33 | **표 안 글씨** |
| 2 | `--fs-본문` | **14px** | 400 | **1.57** | 설명문 · 입력칸 |
| 3 | `--fs-카드제목` | **17px** | 600 | 1.35 (문단은 1.59) | 카드 머리 |
| 4 | `--fs-섹션제목` | **24px** | 600 | 1.29 | 구역 머리 |
| 5 | `--fs-화면제목` | **32px** | 600 | 1.22 | 페이지 머리 |
| 6 | `--fs-요약숫자` | **48px** | 600 | 1.18 | 대표 숫자 **하나**만 |

### 중요도 판단법
- 한 화면에 **등급 5·6 은 각각 하나씩만**
- **등급을 건너뛰어도 됩니다** — 화면제목(32) 다음이 표(12)여도 애플이 그렇게 합니다
- 중간 크기가 필요하다고 느껴지면, **크기가 아니라 굵기·색으로 풀 문제**입니다

## 3. 최소 글자 크기 — 11px

**애플 실측**
- 읽는 글의 최소는 **11px**, 그것도 「애플코리아 유한회사 / 사업자등록번호 / 주소」 같은 **법적 고지 전용**
- 10px 은 페이지 전체에 **딱 2곳**, 내용이 `0` 과 `+` — **글자가 아니라 표식**

**우리 규칙**
- **11px 미만 절대 금지**
- **11px 은 배지 · 단위 · 법적 고지에만.** 사람이 읽는 문장·표 데이터는 **12px 이상**
- 한글은 알파벳보다 작아 보이므로 애플보다 **보수적으로** 갑니다

> 검사 시점 프로그램 안에 **11px 미만이 329곳**. `8.5px` 짜리도 있습니다.

## 4. 굵기 — 400 / 600 이 전부

**이번 실측에서 가장 놀라운 발견입니다.**

| 페이지 | 굵기 분포 |
|---|---|
| 구입하기 | **400(272곳) · 600(64곳)** — **700 이 아예 없음** |
| 소개(검정 구역) | 17·19·21·24·32·48·56px **제목까지 전부 600** |
| 홈 | 400(124) · 600(20) · **700(7)** |

**애플은 굵은 글씨를 거의 쓰지 않습니다.** 32px·48px 대형 제목도 700 이 아니라 **600** 입니다.

**우리 규칙**
- `400` 본문 / `600` **제목·강조의 기본값** / `700` **예외** (표 헤더처럼 아주 작은 글씨를 도드라지게 할 때만)
- `300` `500` `800` `900` 금지 — 현재 프로그램에 **800 이 427곳** 있습니다

## 5. 자간 — 0 이 기본

**애플 실측**

| 크기 | 자간 |
|---:|---|
| 11 · 12 · 14 · 17 · 32 · 48 · 56px | **0 (normal)** |
| 19 · 21 · 24px | **+0.01em 안팎** (미세 양수) |

**애플은 한국어에서 자간을 건드리지 않습니다.** 음수 자간은 영문 대형 헤드라인의 관습이라 한글에는 맞지 않습니다.

> **정정**: 제가 앞서 정했던 `−0.03em` 은 애플 방식이 아니었습니다. **0 으로 바꿉니다.**
> 현재 프로그램에 음수 자간이 **34곳**(`-0.03em` 포함) 있습니다.

## 7. 색

### 파랑이 역할별로 3가지입니다 (실측)

| 역할 | 색 | 실측 |
|---|---|---|
| **버튼 배경** | `#0071E3` | 홈 배경색 3위(9곳) |
| **링크 글자** | `#0066CC` | 홈 15곳 · 구입 7곳, **밑줄 있음** |
| **검정 구역 링크 · 포커스** | `#2997FF` | 소개 11곳 |

> iOS 의 `#007AFF` 는 **웹에서 안 씁니다.** 제가 앞서 정한 값이 틀렸습니다.

### 글자색은 「검정 투명도」로

**애플은 본문 회색을 회색 hex 가 아니라 검정 투명도로 만듭니다.**

| 이름 | 값 | 실측 |
|---|---|---|
| `--글자-진하게` | `rgba(0,0,0,.88)` | 10곳 |
| `--글자-기본` | `rgba(0,0,0,.80)` | 12곳 |
| `--글자-보조` | `rgba(0,0,0,.72)` | **58곳 — 1위** |
| `--글자-흐리게` | `rgba(0,0,0,.56)` | 4곳 |

바탕이 바뀌어도 저절로 어울립니다. 회색 hex 를 새로 만들 필요가 없습니다.

### 회색 (실측 hex)
`#FAFAFC` · `#F5F5F7`(바탕 1위) · `#E8E8ED` · `#D2D2D7`(선 1위) · `#86868B` · `#6E6E73` · `#424245` · `#1D1D1F`(본문 1위)

### 의미 색 — 절대 바꾸지 않습니다
빨강 `#FF3B30` 손실 · 초록 `#34C759` 이익 · 주황 `#FF9500` 주의 · 파랑 동작.
예쁘다고 바꾸면 금전 사고로 이어집니다.

### 주문 상태 배지 6계열
회색(결제대기·결제완료) / 하늘(배송대기중·배송준비중) / 파랑(배송중) / 초록(배송완료·구매확정) / 주황(취소·반품·교환 **요청**) / 빨강(취소·반품·교환 **완료**)

## 11. 여백 — 7단 (4의 배수)

애플의 실측 여백은 반응형 계산값이라 8 · 11 · 15 · 17 · 24 · 34 · 44 · 48 · 56 으로 흩어집니다.
그중 **8 이 압도적 1위**(50곳 · 33곳)이고 큰 값은 24 · 48 · 56 입니다.
→ 우리는 **경향만 가져와 4의 배수 7단으로 고정**합니다.

| 이름 | 값 | 쓰는 곳 (이것 외에는 쓰지 않는다) |
|---|---:|---|
| `--sp-1` | 4px | 아이콘↔글자 · 배지 안 위아래 · 라벨↔값 |
| `--sp-2` | 8px | 배지 안 좌우 · **표 칸 위아래** · 버튼 안 위아래 |
| `--sp-3` | 12px | **표 칸 좌우** · 버튼 안 좌우 · 알약 안 좌우 |
| `--sp-4` | 16px | 카드 안 항목 사이 · 필터 줄 위 |
| `--sp-5` | 24px | **카드 안쪽** · 구역 안쪽 위아래 |
| `--sp-6` | 32px | **화면 좌우 여백** · 상단 여백 |
| `--sp-7` | 48px | 구역과 구역 사이 |

- **애매하면 작은 쪽**을 고릅니다
- **6 · 9 · 10 · 14 · 18px 같은 사이 값을 새로 만들지 않습니다.** 현재 프로그램에서 가장 많이 쓰이는 값이 하필 6px(986곳) · 10px(980곳) · 14px(937곳) · 9px(845곳) 입니다

## 12. 정렬 — 기본은 왼쪽, 가운데는 예외

**애플 실측: 왼쪽 72~76% vs 가운데 24~28%.** 가운데 정렬은 생각보다 훨씬 적게 씁니다.

| 대상 | 정렬 | 클래스 | 왜 |
|---|---|---|---|
| 금액 · 수량 · 비율 | **오른쪽** + 자릿수 세로 정렬 | `.숫자` `.num` | 자릿수를 눈으로 셉니다 |
| 상품명 · 옵션 · 주소 · 이름 | 왼쪽 | `.글` `.txt` | 읽기 시작점이 같아야 합니다 |
| 주문번호 · 송장번호 · 우편번호 | **왼쪽** + 자릿수 맞춤 | `.번호` | 숫자지만 **계산하지 않습니다** |
| 날짜 · 시각 | 왼쪽 | `.글` | 형식이 고정이라 이미 맞습니다 |
| 상태 배지 · 아이콘 · 체크박스 | 가운데 | `.표식` `.ctr` | 폭이 일정한 **짧은 표식**만 |
| 버튼 안 글자 | 가운데 | (자동) | |
| 빈 화면 안내 | 가운데 | `.빈화면` | 문단을 가운데 두는 **유일하게 허용된 곳** |
| `A → B` 비교칸 | **3칸** | `.ds-비교` | 왼쪽값 우측 │ 화살표 가운데 │ 오른쪽값 좌측 |

**헤더 정렬 = 값 정렬.** 예외 없습니다.

### 금지 (검사기가 잡습니다)
- ✗ 숫자를 가운데 정렬 · ✗ 헤더와 값의 정렬이 다름
- ✗ 두 줄 이상 문단을 가운데 · ✗ 비교칸을 셀 통째로 정렬

## 13. 강조 — 크기를 키우지 않습니다

**애플 실측 강조 방식 상위 5개**

| 방식 | 실측 |
|---|---|
| 색 농도만 바꿈 (`.72` → `.88`) | 178곳 · 57곳 |
| 오히려 **흐리게** (보조 정보로 내림) | 34곳 |
| 굵기만 400 → 600 | 14곳 |
| 링크 파랑으로 | 6곳 |

**크기를 바꾸거나 배경을 칠하는 강조는 한 건도 없었습니다.**

**우리 규칙**
- `.강조` 굵기 400→600 / `.진하게` 색 농도 / `.흐리게` 덜 중요한 것 / `.수치강조` 숫자
- ✗ 강조하려고 **글자 크기를 키우지 않습니다**
- ✗ 강조하려고 **배경을 칠하지 않습니다** (형광펜 금지)

## 적용 방법

### 크기·여백·둥글기
`:root` 에 있으므로 어디서든 바로 씁니다.
```css
padding: var(--sp-5);
font-size: var(--fs-표);
border-radius: var(--r-카드);
```

### 색
화면 바깥 상자에 `class="ds"` 를 붙인 곳에만 적용됩니다.
```html
<section class="screen ds">          <!-- 밝은 화면 -->
<section class="screen ds ds-dark">  <!-- 어두운 화면 -->
```
기존 `--ink` `--sub` `--line` `--primary` 에 그대로 연결해 두었으므로
**이미 있는 `var(--…)` 는 한 줄도 고칠 필요가 없습니다.**

`ds` 글자만 지우면 즉시 되돌아갑니다.

## 금지 목록

| 하면 안 되는 것 | 대신 |
|---|---|
| `font-size:13px` | `var(--fs-표)` 또는 `var(--fs-본문)` |
| `font-size:10px` | **11px 미만 금지** |
| `font-weight:800` | `var(--fw-강조)` (600) |
| `letter-spacing:-0.03em` | **0** (한글은 자간을 안 건드립니다) |
| `box-shadow:...` | **1px 선** 또는 배경 밝기 차이 |
| `padding:18px` | `var(--sp-4)` 또는 `var(--sp-5)` |
| `color:#3182F6` | `var(--primary)` |
