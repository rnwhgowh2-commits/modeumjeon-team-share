**근본 원인은 변수를 안 써서가 아닙니다.** `var(--…)` 는 이미 2,443곳에서 쓰고 있었습니다.
문제는 **같은 이름을 화면마다 다시 정의**한 것입니다.

- `--sub` → `#8B95A1`(5개 파일) vs `#6B7684`(5개 파일) — 정확히 반반으로 갈림
- `--ink` `--line` `--line2` → 각각 12개 · 12개 · 9개 파일에서 따로 정의
- `--red` 4가지 값, `--green` 4가지 값

이름은 같은데 값이 달라, 한 곳을 고쳐도 다른 화면은 안 바뀝니다. 이것이 "디자인이 불규칙해지는" 구조입니다.

## 1. 글자 — 중요도 7등급

**애플 공홈(apple.com/kr) 실측(2026-07-30)에 맞춘 값입니다.** 7단 전부 애플이 실제로 쓰는 크기입니다.

| 등급 | 이름 | 크기 | 굵기 | 줄간격 | 쓰는 곳 |
|---:|---|---:|---:|---:|---|
| 0 | `--fs-배지` | **11px** | 600 | 1.35 | 배지 · 단위(원·개·%) · 법적 고지 |
| 1 | `--fs-표` | **12px** | 400·600 | 1.35 | **표 안 글씨** — 우리도 애플도 최다 |
| 2 | `--fs-본문` | **14px** | 400 | **1.6** | 설명문 — 여러 줄을 읽으므로 넉넉하게 |
| 3 | `--fs-카드제목` | **17px** | 600 | 1.3 | 카드 머리 — 한 줄짜리라 좁게 |
| 4 | `--fs-섹션제목` | **24px** | 700 | 1.2 | 구역 머리 |
| 5 | `--fs-화면제목` | **32px** | 700 | 1.15 | 페이지 머리 |
| 6 | `--fs-요약숫자` | **48px** | 700 | 1.15 | 대표 숫자 **하나**만 |

**줄간격은 자동입니다.** `class="ds"` 안에서는 기본 1.35 가 걸리고, 제목류는 위 표대로 자동 적용됩니다.

### 중요도 판단법
- 한 화면에 **등급 5·6 은 각각 하나씩만**. 두 개면 어느 게 중요한지 사라집니다
- **등급을 건너뛰어 씁니다** — 화면제목(32) 바로 다음이 표(12)여도 됩니다. 애플이 그렇게 합니다
- 중간이 필요하다고 느껴지면, 그건 **크기가 아니라 굵기·색으로 풀 문제**입니다

## 2. 최소 글자 크기 — 11px

**애플 공홈 실측 근거**
- 읽는 글의 최소는 **11px** 이었고, 그것도 「애플코리아 유한회사 / 사업자등록번호」 같은 **법적 고지 전용**입니다
- 10px 은 페이지 전체에서 딱 **2곳**, 내용이 `0` 과 `+` — **글자가 아니라 표식**이었습니다

**우리 규칙**
- **11px 미만 절대 금지** (읽을 수 없습니다)
- **11px 은 배지 · 단위 · 법적 고지에만.** 사람이 읽는 문장·표 데이터는 **12px 이상**
- 한글은 알파벳보다 작아 보입니다. 애플보다 **더 보수적으로** 가야 합니다

> 검사 시점(2026-07-30) 프로그램 안에 **11px 미만 글자가 329곳** 있었습니다. 8.5px 짜리도 있습니다. 화면을 옮길 때 함께 올립니다.

## 3. 굵기 — 3단
`400` 본문 / `600` 강조 / `700` 제목.
애플 공홈 실측도 정확히 **400(148곳) · 600(29곳) · 700(7곳)** 세 가지뿐이었습니다.
`300` `500` `800` `900` 금지 — 현재 프로그램에 `800` 이 427곳 있습니다.

### 자간 — 글자가 클수록 좁게
`--ls-큰글씨` −0.03em (32·48px) / `--ls-제목` −0.015em (17·24px) / `--ls-본문` −0.005em (11·12·14px)

## 4. 여백 — 7단 (4의 배수)

**어디에 어느 단계를 쓰는지까지 규칙입니다.** 값만 정하고 용도를 안 정하면 다시 흩어집니다.

| 이름 | 값 | 쓰는 곳 (이것 외에는 쓰지 않는다) |
|---|---:|---|
| `--sp-1` | 4px | 아이콘↔글자 · 배지 안 위아래 · 라벨↔값 |
| `--sp-2` | 8px | 배지 안 좌우 · **표 칸 위아래** · 버튼 안 위아래 |
| `--sp-3` | 12px | **표 칸 좌우** · 버튼 안 좌우 · 알약 안 좌우 |
| `--sp-4` | 16px | 카드 안 항목 사이 · 필터 줄 위 |
| `--sp-5` | 24px | **카드 안쪽** · 구역 안쪽 위아래 |
| `--sp-6` | 32px | **화면 좌우 여백** · 상단 여백 |
| `--sp-7` | 48px | 구역과 구역 사이 |

### 판단 규칙
- **애매하면 작은 쪽**을 고릅니다. 커지면 한 화면에 안 들어옵니다
- **세로 간격도 이 7개만** 씁니다. 6 · 9 · 10 · 14 · 18px 같은 사이 값을 새로 만들지 않습니다
- 현재 프로그램에서 가장 많이 쓰이는 값이 **6px(986곳) · 10px(982곳) · 14px(937곳) · 9px(845곳)** 입니다. 전부 규칙 밖입니다

## 6. 색 — 애플 시스템 색만

애플이 공식 배포하는 색만 씁니다. 그 외 색은 금지입니다.

| 용도 | 값 | 변수 |
|---|---|---|
| 주 동작·링크 | `#007AFF` | `--primary` `--blue` |
| 정상·이익 | `#34C759` | `--green` `--색-정상` |
| 오류·손실 | `#FF3B30` | `--red` `--색-위험` |
| 주의·대기 | `#FF9500` | `--amber` `--색-주의` |
| 배송 진행 | `#5AC8FA` | `--상태-준비` |

회색 6단: `#F5F5F7` `#E8E8ED` `#D2D2D7` `#86868B` `#424245` `#1D1D1F`

### 의미는 절대 바꾸지 않습니다
빨강=손실 · 초록=이익 · 주황=주의 · 파랑=동작. 예쁘다고 바꾸면 금전 사고로 이어집니다.

### 주문 상태 배지 6계열
기존 12개 통일 상태와 1:1로 맞췄습니다.

| 계열 | 상태 |
|---|---|
| 회색 | 결제대기 · 결제완료 |
| 하늘 | 배송대기중 · 배송준비중 |
| 파랑 | 배송중 |
| 초록 | 배송완료 · 구매확정 |
| 주황 | 취소요청 · 반품요청 · 교환요청 |
| 빨강 | 취소완료 · 반품완료 · 교환완료 |

## 7. 정렬 — 기본은 왼쪽, 가운데는 예외

**애플 공홈 실측: 왼쪽 140곳(76%) vs 가운데 44곳(24%).** 가운데 정렬은 생각보다 훨씬 적게 씁니다.

| 대상 | 정렬 | 클래스 | 왜 |
|---|---|---|---|
| 금액 · 수량 · 비율 | **오른쪽** + 자릿수 세로 정렬 | `.숫자` `.num` | 자릿수를 눈으로 셉니다 |
| 상품명 · 옵션 · 주소 · 이름 | 왼쪽 | `.글` `.txt` | 읽기 시작점이 같아야 합니다 |
| 주문번호 · 송장번호 · 우편번호 | **왼쪽** + 자릿수 맞춤 | `.번호` | 숫자지만 **계산하지 않습니다** → 왼쪽 |
| 날짜 · 시각 | 왼쪽 | `.글` | 형식이 고정이라 이미 세로로 맞습니다 |
| 상태 배지 · 아이콘 · 체크박스 | 가운데 | `.표식` `.ctr` | 폭이 일정한 **짧은 표식**만 |
| 버튼 안 글자 | 가운데 | (자동) | |
| 빈 화면 안내 | 가운데 | `.빈화면` | 문단을 가운데 두는 **유일하게 허용된 곳** |
| `A → B` 비교칸 | **3칸** | `.ds-비교` | 왼쪽값 우측정렬 │ 화살표 가운데 │ 오른쪽값 좌측정렬 |

### 표 헤더
**헤더 정렬 = 값 정렬.** 예외 없습니다. 다르면 칸이 어긋나 보입니다.

### 금지 (검사기가 잡습니다)
- ✗ **숫자를 가운데 정렬** — 자릿수를 눈으로 셀 수 없습니다
- ✗ **헤더와 값의 정렬이 다름**
- ✗ **두 줄 이상 문단을 가운데** — 줄마다 읽기 시작점이 흔들립니다
- ✗ **비교칸을 셀 통째로 정렬** — 값 길이가 행마다 달라 화살표가 어긋납니다

## 적용 방법

### 크기·여백·둥글기
`:root` 에 있으므로 어디서든 바로 씁니다.
```css
padding: var(--sp-5);
font-size: var(--fs-표);
border-radius: var(--r-카드);
```

### 색
화면 바깥 상자에 `class="ds"` 를 붙인 곳에만 적용됩니다.
```html
<section class="screen ds">   <!-- 밝은 화면 -->
<section class="screen ds ds-dark">   <!-- 어두운 화면 -->
```
기존 `--ink` `--sub` `--line` `--primary` 에 그대로 연결해 두었으므로,
**이미 있는 `var(--…)` 는 한 줄도 고칠 필요가 없습니다.**

화면 하나씩 옮길 수 있고, `ds` 글자만 지우면 즉시 되돌아갑니다.

## 금지 목록

| 하면 안 되는 것 | 대신 |
|---|---|
| `font-size:13px` | `var(--fs-표)` 또는 `var(--fs-본문)` |
| `padding:18px` | `var(--sp-4)` 또는 `var(--sp-5)` |
| `color:#3182F6` | `var(--primary)` |
| 화면 안에서 `--ink:` 다시 정의 | tokens.css 한 곳에서만 |
| `style="..."` 로 새 부품 만들기 | `.ds-카드` `.ds-배지` `.ds-알약` 사용 |
| 초록을 경고로 사용 | 경고는 반드시 주황 |
| 숫자를 가운데 정렬 | 숫자는 오른쪽 + 자릿수 정렬 |
