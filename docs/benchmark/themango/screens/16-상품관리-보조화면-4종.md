| **넘버링 대상옵션** | 첫번째 / 두번째 / 세번째 / 네번째 / 다섯번째 옵션 |
| 실행 | `[옵션넘버링시작]` `[옵션넘버링 삭제시작]` (검색결과 모든상품) |

검색 결과 **159,522개**

### 게이트 ⚪ **보류**
- Job: **옵션명이 못 읽을 글자이거나 중복일 때** 번호로 대체 (매뉴얼 `115`: *"중국·일본 사이트처럼 옵션명이 못 읽을 글자일 때"*)
- **G3** — 이건 **해외 소싱의 문제**다. 우리는 **국내 소싱**이라 옵션명이 한글로 정상적으로 온다
- 🔵 우리는 오히려 반대 방향의 자산이 있다 — `ColorDict`(색상 정규화 사전) · `AliasMapping`(별칭→캐노니컬) · **축 맞추기**(소싱처 옵션을 「조합」 아닌 「축」으로)
- ⇒ **옵션명을 숫자로 바꾸는 건 우리에게 퇴보다.** 보류가 아니라 사실상 🔴에 가깝다

## 🎯 화면 우상단에 있는 결정적 버튼
> **`[G마켓 옵션등록제한 카테고리 상품조회]`**

⇒ §13 에서 발견한 *"옥션2.0은 일부 카테고리에 대해 상품등록시 옵션등록을 제한한다"*의 **실물 도구**다.
**그 제약에 걸린 상품을 찾아주는 조회 버튼**이 여기 있다.

| 게이트 | 결과 |
|---|---|
| **G1** | ✅ 이 버튼이 존재한다는 것 자체가 **실제로 겪는 문제**라는 증거 |
| **G2** | ❌ 우리 preflight 에 이 검사가 없다 |
| **G4** | 모르면 등록이 실패하고 왜인지 모른다 |
| **판정** | 🟢 **채택** — 우리 등록 preflight 에 **「이 카테고리는 옵션등록 불가」 검사** 추가 |

## 「전송마켓만 삭제」 자체는 🟡
- G2 — 우리는 **판매중지·품절 전송** 배선이 있다([[project_market_stock_send_nostock_vs_purchase.md]])
- 🟡 **형태 바꿔 채택** — 삭제보다 **품절/판매중지가 먼저**다. 삭제는 카테고리 오등록 복구처럼 **되돌릴 수 없을 때만**
- ⚠️ 그리고 화면 하나에서 **166,006개를 마켓에서 통째로 지울 수 있다.** 우리는 이런 버튼을 **전량 대상으로 두지 않는다**
