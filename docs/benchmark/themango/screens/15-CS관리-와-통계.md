# ① CS관리 (`admin_getcs.php`) — 배지 `99+`

## 구조
- 검색: `마켓상품번호 검색` select + 키워드 + `[검색하기]`
- 마켓 계정 select `옥션2.0-<계정> 문의내역` + `[가져오기]` + **`[전체마켓 가져오기]`**
- 안내: *"연동하신 마켓의 **질문/긴급문의/긴급알림** 등에 대한 답변이 가능합니다."*
- 버튼: `[답변템플릿 관리]` `[선택삭제]`
- 필터: `전체마켓보기` · **`미답변(미확인) 문의만 보기`** · `문의수집일자 ▲▼` · `30개씩`
- 표 5열: `마켓(주문번호)` | `문의유형(질문자)` | `문의내용` | `답변여부` | `문의일시(문의수집일자)`
- 행마다: 상품명 + `[상품링크]` `[판매마켓링크]` `[원문링크]` + 문의 본문 + `[답변하기]` + `[삭제]`

## ★ 발견 — **문의유형에 「긴급알림」이 있다**

`상품문의` 외에 **`긴급알림`** 유형이 있고, 여기로 **마켓 운영 공지·패널티 경고**가 들어온다.

실제로 들어온 11번가 알림(요지):
> `[▶발송지연 노출제한 사전 안내◀]`
> 금일 발송예정일인 주문의 **미발송률이 30% 이상**으로 굵어져 안내
> 발송예정일 내 발송처리 되지 않으면 **익일 9시부터 상품 노출을 제한(발송지연 패널티)**
> 발송이 어려운 경우 **「발송지연 안내」를 등록하면 패널티가 유예**
> (셀러오피스 > 주문관리 > 주문상세 > 발송지연 안내 / 주문당 1회)

⇒ 🔴 **이건 돈이 걸린 알림이다.** 놓치면 **상품 노출이 제한**된다.

| 게이트 | 결과 |
|---|---|
| **G1** | ⚠️ **애매** — 데이터는 들어오는데 **`99+` 전부 미답변**. 사장님이 여기서 CS 를 처리하진 않으신다 |
| **G2** | 우리 CS 탭(`/orders/?tab=cs`)은 **취소·반품·교환 + 고객문의**를 다룬다. **마켓 운영 알림은 없다** |
| **G4** | 패널티 경고를 놓치면 노출 제한 = 매출 직결 |

### 판정
- 🟢 **「마켓 운영 알림·패널티 경고 수집」만 채택** — 고객문의가 아니라 **마켓이 나에게 보내는 경고**를 놓치지 않는 축. 우리에게 없다
- ⚪ **CS 답변 기능 자체는 보류** — 사장님이 더망고에서 답변을 안 하신다(99+ 미답변). 우리 CS 탭이 이미 있고, **답변은 마켓 관리자에서 하시는 것으로 보인다**
- 🟡 `답변템플릿 관리` — 우리 CS 탭에 있는지 확인 후 결정

### 🎯 이게 이 화면의 진짜 값어치다
- 「몇 개 긁었나」(수집량) → 「몇 개 살아있나」(§09) → **「무엇을 보고 있나」(조회수)** → 「무엇이 팔렸나」(매출)
- 이 네 숫자를 나란히 놓으면 **어디서 새는지**가 보인다
  - 조회 높은데 매출 0 → **가격·상세·상품명 문제**
  - 조회도 0 → **카테고리·검색태그 문제**
  - 조회 높은데 삭제됨 → **다시 확보해야 할 상품**
