## ★ 엑셀 컬럼 전 18개 (A~R) — 더망고 상품 데이터 모델

| 컬럼 | 항목 | 필수 | 설명 (원문) |
|---|---|---|---|
| **A** | 상품명 | **필수** | 상품명 |
| **B** | 카테고리 | **필수** | 카테고리 이름 — 템플릿 **시트2 「카테고리목록」** 의 값을 그대로 복사. 예: `가구·홈·데코 > 인테리어폴리워 > 중대형 화분` |
| **C** | 브랜드 | **필수** | 브랜드명 |
| **D** | 대표이미지 | **필수** | 업로드한 이미지 **파일명** 또는 **외부 URL** |
| **E** | 통화 | **필수** | KRW / USD / CNY / EUR / JPY 등 |
| **F** | 가격 | **필수** | **현지 통화 기준** 숫자 |
| **G** | 재고 | **필수** | 숫자 |
| H | **원문URL** | - | 해외 상품 페이지 URL |
| I | 모델명 | - | |
| **J** | **검색필터명** | - | 🎯 **매칭 시도 → 실패/빈값이면 「수동등록상품」 자동등록** |
| K | 추가이미지 | - | 파일명/URL **쉼표·줄바꿈**으로 구분 |
| L | 상세페이지HTML | - | 본문 HTML — 자동 wrapper `<div style="width:800px">` 적용 |
| M | 옵션그룹 | - | 옵션명 **쉼표** 구분 (예: `색상,사이즈`) |
| N | 옵션값 | - | 옵션 조합 **줄바꿈** 구분 (예: `빨강,M` / `빨강,L`) |
| O | 옵션가격 | - | **옵션값 순서와 동일하게** 줄바꿈 구분 |
| P | 옵션재고 | - | 동일 |
| Q | 옵션이미지 | - | 동일 (파일명/URL) |
| **R** | **판매자상품관리코드** | - | 🎯 아래 상세 |

### 🎯🎯 R 컬럼 = **upsert 키** (원문 그대로)
> **"판매자 전용상품관리 코드. 상품검색시 수집사이트상품번호로 검색이 가능합니다.
> 해당 코드는 **유니크한 번호**로 **중복 등록될 수 없습니다.**
> 동일한 코드가 들어오면 해당 코드와 동일한 상품이 **업데이트** 됩니다."**

⇒ **같은 엑셀을 다시 올려도 중복이 안 생기고 갱신된다.**
🟢 **채택 확정.** 우리 대량등록에 엑셀 입구를 만들 때 **반드시 이 upsert 키를 둔다.**
🎯 **이관에도 쓸 수 있다** — 우리 SKU 코드를 R 에 넣어두면 양쪽 시스템이 같은 열쇠로 짝을 맞춘다.

### 🎯 J 컬럼의 정직한 폴백
> "매칭 시도 → 실패/빈값이면 **「수동등록상품」 자동등록**"

없는 필터명을 넣으면 **조용히 버리거나 에러 내지 않고**, 「수동등록상품」이라는 **명시적 바구니**에 담는다.
🟢 **채택** — 우리 「폴백 금지」 원칙과 충돌하지 않는다. 값을 **지어내는 게 아니라 「출처 미상」으로 표시**하는 것이기 때문.

## 🔴 따라하면 안 되는 것 — 옵션 5컬럼 「줄바꿈 순서 정렬」

```
M 옵션그룹   색상,사이즈
N 옵션값     빨강,M
             빨강,L
O 옵션가격   19900
             21900
P 옵션재고   5
             3
Q 옵션이미지 a.jpg
             b.jpg
```

**N·O·P·Q 네 컬럼이 「같은 줄 번호」로만 짝지어진다.** 줄 하나가 밀리면 **가격과 재고가 통째로 어긋난다.**

🔴 **채택 금지.** 이 프로젝트에서 가격·재고 오류는 곧 금전 손실이다([[project_silent_failure_bug_class]]).
🟢 **우리 방식**: 옵션 1행 = 엑셀 1행 (long format). 상품 여러 행이 `판매자상품관리코드` 로 묶인다.
정렬 의존이 사라지고, 검토 테이블에서 행 단위로 오류를 짚을 수 있다.

## 그 밖에 읽히는 것

| 관찰 | 뜻 |
|---|---|
| **카테고리를 「이름 문자열」로 받는다** (시트2에서 복사) | 코드가 아니라 경로 문자열. 오타에 약하지만 사람이 쓰기 쉽다. 🟡 우리는 **드롭다운 + 코드**가 나을 것 |
| **통화 컬럼이 필수** | 해외 구매대행 전제. 우리는 KRW 고정이라 **컬럼 자체가 불필요** |
| **가격은 「현지 통화 기준」** | 환율 적용은 더망고가 한다 |
| **원문URL 이 선택(-)** | 소싱처 URL 없이도 상품을 만들 수 있다 = **수기 상품**을 허용 |
| **이미지를 파일명으로도 받는다** | 엑셀 + 이미지 폴더를 같이 올리는 방식 |
| **상세페이지HTML 에 자동 wrapper** | `width:800px` 강제 — 마켓 상세 폭 표준 |
