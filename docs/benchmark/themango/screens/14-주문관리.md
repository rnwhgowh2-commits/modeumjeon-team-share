## ★★★ 최대 수확 — 사장님이 요구하셨던 「전후 가격 표시」의 실물

주문 행에 이렇게 찍혀 있다:
```
[GSShop.com] 매장정품 [28% OFF] … (BI5871G035) 243307 (1092113981)
        / KRW 89,910 → 83,070   🔴[가격변동]
```

= **마켓에 등록할 당시의 소싱처 가격 → 지금 소싱처 가격**을 나란히 보여주고, 다르면 **빨간 `[가격변동]` 배지**를 단다.

### 이건 사장님이 이미 확정하신 요구사항과 정확히 같다
> [[project_bulk_register_phase1b_pricing_model]] §대량등록의 본질:
> *"**주문 시점에도 그 가격 그대로 주문되는 것**이 관건. 차이 나면 **화면에 전후 가격 전부 표시**(숨기거나 하나로 뭉개지 말 것). 역마진 전환 시 강조 경고."*

| 게이트 | 결과 |
|---|---|
| **G1** | ✅ **실제로 뜨고 있다** — 주문 목록 첫 행에 바로 보임 |
| **G2** | 우리 설계서에 **요구는 있으나** 주문 화면에 붙은 적 없음 (*"전후 가격 표시 UI 는 시안 확인 후 구현"* 상태로 남아 있음) |
| G4 | 역마진 주문을 못 잡으면 팔수록 손해 |
| G5 | 없음 |

⇒ 🟢 **채택 확정 (최우선급).** 다만 **우리는 한 걸음 더 간다**:
- 더망고는 **소싱처 표면가**의 전후만 본다
- 우리는 **최종매입가**(카드·캐시백·경유 차감 후)의 전후를 봐야 한다. 표면가가 그대로여도 혜택이 사라지면 역마진이 된다
- 🔴 **역마진 전환 시 강조 경고**를 함께 붙인다 (더망고엔 없다 — 그냥 `[가격변동]` 만)

## L4/L5 — 주문 행 1건의 밀도

### 상단 줄
`[쿠팡 | <계정>] <주문번호>` + `[주문번호복사]` `[마켓관리자페이지]` + 🔴`[통관부호없음]` `[메세지전송]`

### 상품 줄
`[<소싱처>] <상품명> (<모델>) <번호> (<원문번호>) / KRW 89,910 → 83,070` 🔴`[가격변동]`
`주문옵션(검정색 140)` `[옵션매칭]`
`구매노출상품 ?` : 원문 상품명·옵션 그대로

### 🎯 버튼 14개 (한 주문 행에)
`주문정보` · `가격재고이력` · `상품링크` · `원문링크` · `판매마켓링크` · `상품주문링크` · `배송대행지` · `통관&국내배송조회` · `택배배송조회` · `개별출력메모&마켓전송` · **`전송마켓/품절처리`** · **`마켓상품삭제`** · `관련CS내역` · `SMS전송` · `식겁대상품록`

⇒ 🟡 **G4 — 14개는 너무 많다.** 우리는 실제로 누르는 것만 남긴다.
🎯 다만 **`가격재고이력`** 과 **`관련CS내역`** 은 값어치가 크다 — 주문에서 상품 이력·CS로 바로 건너뛴다.

### 우측 입력칸 6개
`상품주문번호` · `구입금액(신고금액)` · `트래킹번호` · `--택배사선택--` · **`국내송장번호`** · `국제운송료`

### 상태 3종
`주문상태` select (해외 현지배송중 / 결제완료 / 배송대기중 …) · `마켓상태` select (특이사항없음) · `배송대행` select
\+ **`간편메모`** 텍스트박스 (주문마다) + `[삭제]` `[주문로그]`

🎯 **`[주문로그]`** — 주문 1건의 변경 이력. §12 전송로그와 같은 계열.
