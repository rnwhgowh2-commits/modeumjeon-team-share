- **사이트 검색** 입력칸
- 목록 (각 행: ★즐겨찾기 · 사이트명 · 🔗원문링크 · [국가])

### 우측: 선택 사이트별 수집 폼

#### eBay (API형)
- 셀렉트 `셀러검색` + 텍스트 `검색하실 이베이 셀러명을 입력해주세요!` + 버튼 `셀러전체 상품검색하기`
- `** ebay API는 최대 1만개의 상품을 저장할 수 있습니다.`
- `** 판매자(셀러) 상품을 한번에 저장할 수 있습니다.` + 버튼 `셀러아이디 찾는 방법 (FAQ)`
- 🔴 현재 상태: `※ 이베이 APP ID API 키가 설정되어 있지 않습니다.` (미사용)

#### MUSINSA (리스팅 URL형)
- 텍스트: `데이터를 수집하실 검색페이지 또는 카테고리 URL를 http://를 포함하여 입력해주세요.`
- 버튼: `URL 상품검색하기`
- `** 해당 사이트의 리스팅결과에 나오는 모든 상품을 한번에 저장할 수 있습니다.`

##### 🎯 무신사 전용 경고 3건 (소싱처별 실측 노하우 — 이게 진짜 자산)
1. **"일부 리스팅 페이지는 특정 페이지로 이동이 불가능한 사이트입니다. 전체 저장시에는 반드시 저장하실 상품개수를 입력하셔야 상품 수집이 가능합니다."**
   → 무신사는 페이지 점프가 안 되므로 **저장상품수 입력이 사실상 필수**
2. **"검색 결과에 일부 이미지가 표시되지 않을 수 있습니다. 이는 상품 수집에는 영향이 없습니다."**
3. 🔴 **"이미지 다운로드 및 이미지 외부 링크를 차단한 사이트로, 「이미지우회 부가서비스」를 이용하셔야 이미지가 정상적으로 보여집니다."**
   → **무신사 이미지는 핫링크가 막혀 있다. 별도 유료 부가서비스로 우회.**
   → 우리도 무신사 상품을 마켓에 올리려면 **이미지 재호스팅이 필수**. ([[project_r2_image_storage]] 이사 미실행 건과 직결)

### 2. 금지어 템플릿 — **마켓별로 따로 있다**
| 값 | 이름 |
|---|---|
| 60 | 스마트스토어 금지어 |
| 61 | 롯데온 금지어 |
| 62 | 옥션 금지어 |

| 86 | 쿠팡 금지어 |

🟢 **채택**: 마켓마다 금지 단어가 다르다는 현실을 **수집 시점에** 반영. 우리는 등록 실패로 뒤늦게 알게 된다.

### 3. 저장상품수 — 주의문 3줄
- 조건 만족 상품 중 **순서대로** N개만
- 미입력 시 검색된 전 상품
- 🔴 **"입력하신 개수에서 이미 등록된 상품, 금지어 적용 등 일부 상품은 제외되고 저장될 수 있습니다."**
  → **N개 요청 ≠ N개 저장.** 정직한 고지.

### 6. 🎯 적용카테고리 — **「더망고 카테고리」라는 자체 표준 계층이 있다**
> "**더망고 카테고리**를 선택하신 후 저장하시면, **자동으로 마켓카테고리가 매핑되어 저장**됩니다."
> "더망고 카테고리의 매핑정보는 `[정책적용]-[카테고리 관리 및 정책적용]` 메뉴에서 THE MANGO 카테고리를 선택하시면 확인 및 수정 가능합니다."

⇒ **3단 카테고리 구조**:
```
소싱처 카테고리  →  【더망고 카테고리】(자체 표준)  →  6개 마켓 카테고리
```
🟢 **채택 최우선.** 우리는 **소싱처↔마켓 2단 직결**(N×M 매핑)이라, 마켓이 늘 때마다 매핑이 곱셈으로 늘어난다. 중간 표준을 두면 **N+M**이 된다. 우리 카테고리 사전 59,048건이 이미 있으니 중간층만 얹으면 된다.

### 8. 번역 후 저장 — 실제 옵션
| 구분 | 값 |
|---|---|
| 번역기 | **더망고 무료 번역기**(`browser_translator`) / 구글(`google`) / DeepL(`deepl`) / 네이버 클라우드(`naver_cloud`) |
| 원문 언어 | 영어 · 중국어(간체) · 중국어(번체) · 일본어 · 독일어 · 이탈리아어 · 프랑스어 · 스페인어 |
| 번역 언어 | 한국어 · 영어 · 일본어 |
| 번역 항목 | ☐상품명 ☐옵션명 ☐상품설명 ☐스펙 |

💡 `더망고 AI 번역기는 최신 버전의 Chrome(웨일) 브라우저에서만 이용 가능` — **브라우저 내장 번역 API를 쓴다**(무료의 정체).

### 9. 랜덤키워드
- 템플릿 select — 현재 등록된 것: **`마침표`** (value 102) + `[랜덤키워드 템플릿]` 관리 버튼
- 개수: 1~10개
- 위치: **상품명 앞** / **상품명 뒤**

⇒ 사장님은 이미 「마침표」 템플릿을 쓰고 있다. **상품명 뒤에 마침표를 랜덤 개수로 붙여 마켓 중복 상품 판정을 피하는 기법.**
🟡 **판정 보류**: 효과는 있으나 마켓 어뷰징 정책 저촉 여지. 사장님 확인 필요.

### 10. 🎯 옵션저장 — `옵션저장안함`
> "본 옵션을 체크하시면 **옵션이 있는 상품이 모두 옵션이 없는 단품 상태로 저장**됩니다."

⇒ 옵션을 통째로 버리고 단품화. 재고관리를 포기하는 대신 등록이 단순해진다.
🔴 **우리는 채택 금지.** 우리는 옵션별 재고·가격이 생명이다(오버셀 = 계정 위험). 다만 **「옵션 없는 상품」으로 다루는 모드**가 필요한 소싱처가 있을 수 있으니 기록.

| **가격전략** | `보통가격` · `고마진` · `저마진` · `저마진 배송료` · `배송비` |
| **기간** | `_3개월` |
| **마켓/스토어 조합** | `(박스+마켓)` `(위시+바이+타임)` `(타임+박스)` `(위시)` `(바이)` `-마켓` `-웨이` `-위시` → **스토어 별칭 7종: 위시·바이·타임·박스·마켓·웨이 + α** |
| **제외 표기** | `(쿠팡X)` · `롯데온x` |
| **계정** | `rnwhgowh` ~ `rnwhgowh7` → **마켓 계정 7개** |
| **특수** | `소명등록용 rnwhgowh1~7` (계정별 소명 전용 정책 8개) · `기본설정` · `test` · `- 복사본` 다수 |

### 여기서 읽히는 것
1. 🔴 **정책 축이 4차원이다** — 소싱처 × 브랜드 × 가격전략 × 마켓계정. 그래서 138개로 폭발했다.
2. 🔴 **`- 복사본`, `- 복사본 - 복사본` 이 6개 이상** — 정책 관리가 **복사 후 수정**으로 굴러가고 있다는 뜻. 상속·템플릿 구조가 없어서 생기는 현상.
   ⇒ **우리가 개선할 지점**: 정책을 「베이스 + 오버라이드」로 쪼개면 138개가 수십 개로 준다.
3. 🔴 **`소명등록용` 정책이 계정마다 따로 8개** — 마켓 소명(정품 증빙) 대응 전용. 실무 필수 개념인데 우리에겐 없다.
4. 🟢 **브랜드 단위가 운영의 실제 최소 단위다.** 우리 `CrawlWeightRule.scope_type=brand`·`effective_option_brand()` 와 정확히 맞물린다.
