## 🔴🔴 정정 — 더망고에도 「정책 출처 표시」가 있다

상품 카드의 적용정책 줄:
> **`적용정책  [ 기본설정 ]  카테고리 정책 적용중`** + `[상품별 개별 정책적용]` `[적용된 정책관리 ▼]` `[적용된 정책 간단히 보기]`

**「기본설정」이라는 정책이 「카테고리 정책」 층에서 왔다**고 상품마다 적어준다.

⇒ §5(용어대응사전)에서 *"값의 출처 표시 — 더망고 ❌ / 우리 `common`·`own` ✅ 🔵🔵 우리 우위"* 라고 썼다. **부분적으로 틀렸다.**
- **더망고**: **정책 단위** 출처 표시 (이 상품의 정책이 4단 중 어느 층에서 왔나) ✅
- **우리**: **값(항목) 단위** 출처 표시 (`from_common_at` → 마켓 공통에서 왔나 직접 고쳤나) ✅
- ⇒ **서로 다른 층의 출처 표시다. 둘 다 필요하다.** 🟢 **더망고 것도 채택** — 우리는 상품 화면에서 「이 상품이 왜 이 정책을 받았나」를 못 보여준다.

> 🔴 **이번 세션 6번째 오판.** 원인은 매번 같다 — **한 화면만 보고 단정**했다. 출처 표시는 정책관리 화면이 아니라 **상품 화면**에 있었다.

🎯 **주목할 4개**
- **`GTIN수정`** — 국제 상품 식별번호(바코드). 마켓이 요구하는 경우가 늘고 있다. 우리에게 없음 🟢
- **`필수구매옵션등록`** — 반드시 고르게 하는 옵션
- **`전송마켓품절처리`** — 삭제 말고 **마켓에서 품절로만** 내리기. 🟢 **채택 가치 큼** (우리 「판매중지」와 대응)
- **`주문내역검색`** — 이 상품의 주문을 바로 조회. 상품↔주문 왕복

### ④ 가격
```
상품가 [____] 원  [가격수정]
계산식 / 원가 : ₩22,900  (상품가 ₩19,900 + 현지배송비 ₩3,000)
※ 가격을 수정하시면 해외 가격은 무시되고, 수정하신 가격으로 반영됩니다.
마켓전송가격  -
```
옵션 있는 상품:
```
대표가격 32,800 원   계산식 / 원가 : ₩9,900
※ 대표가격은 마켓에 전송시 대표로 표시되는 가격입니다. 아래 옵션보기에서 변경 가능.
```

🎯 **`계산식 / 원가` 를 상품 카드에 펼쳐 보여준다** — `원가 ₩22,900 = 상품가 ₩19,900 + 현지배송비 ₩3,000`.
🔵 우리 **fx영수증**이 같은 일을 더 깊게 한다(혜택 단계별 차감까지). **다만 우리는 대량등록 상품 카드에 이걸 안 붙였다** → 🟢 붙일 것.

### 🎯 사장님의 창의적 우회 발견
**국내 소싱인데 「현지배송비 ₩3,000」을 쓰고 있다.**
= 해외 구매대행용 칸을 **국내 배송비 얹기**로 전용(轉用)한 것.
⇒ 우리 설계에서 「해외 축은 전부 버림」이라 했지만, **「원가에 정액을 얹는 칸」은 실제로 쓰이고 있다.** 🟢 **「별도 추가요금」 형태로 남길 것.**
