## ★ 게이트 통과분 — 🟢 채택 3

### 🟢 1. 변수 + **조건부 블록** (템플릿 엔진의 핵심)
변수 13종: `{goods_name}` `{goods_rename}` `{goods_imageN}` `{goods_video}` `{goods_price}` `{goods_site}` `{goods_brand}` `{goods_model}` `{goods_condition}` `{goods_number}` `{goods_site_number}` `{goods_desc}` `{goods_spec}` `{line_space}`

**진짜 값어치는 블록 문법에 있다:**
| 블록 | 동작 |
|---|---|
| `[IMAGE_SET] ~ [/IMAGE_SET]` | 사이의 태그가 **이미지마다 반복** |
| `[IMAGE_SIZE]600[/IMAGE_SIZE]` | 크기 지정. **최대 크기가 지정값 이하면 원본 그대로** |
| `[GOODS_DESC] ~ [/GOODS_DESC]` | **상품설명이 없으면 블록째 안 나온다** |
| `[GOODS_SPEC] ~ [/GOODS_SPEC]` | **스펙이 없으면 블록째 안 나온다** |

- **G2**: 우리 `mode='frame'`(`process_rule_schema.py:208`)에 **반복·조건부 문법이 없다**
- **G4**: 값 없는 칸이 빈 제목만 남기면 상세가 지저분해지고 그건 전환율이다
- **판정 🟢** — 단 변수는 **우리 국내 소싱에 맞게 추림**: `{goods_condition}`(중고/리퍼비시)·`{goods_site}`(amazon/ebay) 는 뺀다

### 🟢 2. `[기본템플릿 복원하기]`
HTML 을 직접 편집시키면 반드시 망가뜨린다. **되돌릴 수 있어야 편집을 시킬 수 있다.**
- **G5** 통과 — 이 버튼이 없으면 HTML 편집 자체를 열면 안 된다
- **판정 🟢** (편집 기능과 **한 세트**)

### 🟢 3. `{goods_desc}` 처리 4택
`이미지, 텍스트 모두 보여주기` / `이미지만` / `텍스트만` / `상품설명 삭제하기`
> *"이미지는 `<img>` 태그에 대해서만 적용됩니다."*

- **G1**: 소싱처 상세는 남의 브랜드 로고·가격·연락처가 박힌 이미지 천지다. **텍스트만 뽑거나 통째로 버리는 선택이 실무상 필수**
- **G2**: 우리 `hide_source_logo`(스위치)로는 부족 — 그건 로고만
- **판정 🟢** — 우리 `mode` 3종(recombine/original/frame)에 **이 4택을 흡수**한다
