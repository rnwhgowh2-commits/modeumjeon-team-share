## 🔴🔴🔴 화면이 적어둔 함정 — 부분 업데이트는 옵션을 죽인다

빨간 글씨 원문 그대로:

> **"가격, 재고만 업데이트 하시는 경우, 옵션이 있는 상품은 현재 있는 옵션에 대해서만 가격 및 재고가 업데이트 됩니다. 현재 수집된 옵션과 다른 옵션은 수집되지 않으며, 현재 수집되어 있는 옵션이 없는 경우 품절로 처리됩니다."**
>
> **"가격 및 재고만 업데이트해야 하는 특별한 경우가 아니라면 반드시 모든 정보 업데이트로 업데이트하시기 바랍니다. 참고로 항목별 업데이트 속도는 100% 동일합니다."**

### 무슨 뜻인가
- 「가격·재고만」 갱신하면 → **소싱처에 새로 생긴 옵션(새 사이즈·색상)이 영영 안 들어온다**
- 기존에 갖고 있던 옵션이 소싱처에서 사라지면 → **품절 처리** (그건 맞다)
- **속도 이득이 0이므로 부분 갱신을 쓸 이유가 없다**

### 🎯 우리에게 던지는 질문 (검증 과제)
우리 갱신 경로에도 같은 함정이 있는가?
- 우리는 크롤이 **항상 전체 옵션을 긁는** 구조로 보이나, `hmall_persize_refresh` 처럼 **일부만 새로 읽는 경로**가 존재한다([[project_bulk_register_phase1b_pricing_model]] M5 메모: *"`reconcile_after_crawl` 은 `POST /api/sources/crawl-result` 한 곳에서만 호출 — 그 경로 안 타는 크롤은 통계 누락"*)
- **판정 = 확인불가.** 확인할 것: 부분 갱신 경로가 **새 옵션을 추가하는가**, 아니면 기존 옵션만 덮는가
- 관련 이력: [[project_lemouton_persize_stock_dropped_at_save]](options[] 미전송으로 사이즈별 재고 증발) · [[project_option_value_rename_vs_ghost_options]](유령 옵션)

⇒ 🟢 **채택할 것은 기능이 아니라 「경고를 화면에 박아두는 태도」다.** 더망고는 자기 시스템의 함정을 숨기지 않고 빨간 글씨로 적었다.

### ② 소싱처 선택 (체크박스 13개 + `사이트검색`)
> *"선택한 항목이 없으면 **모든 사이트 상품을 전송**합니다."*
> *"여러 사이트 동시 업데이트시에는 **위에 나열된 사이트 순서대로** 업데이트가 진행됩니다."*

🔴 **「아무것도 안 고르면 전량」** 이 기본값이다. 165,705개가 한 번에 나갈 수 있다.
⇒ 🔴 **우리는 이 기본값을 따라가지 않는다.** 빈 선택 = 전량은 사고를 부른다. 우리 원칙(빈 값 ≠ 0, 빈 값 ≠ 전체)과 정면 충돌.

### ③ 업데이트 항목 (체크박스 5개)
`✅모든정보 업데이트` / `가격정보 업데이트` / `재고정보 업데이트` / `이미지 업데이트` / `상세설명 업데이트`

> *"선택한 항목이 없으면 상품 업데이트는 생략됩니다."*
> *"본 업데이트는 **원문상품정보를 더망고로** 업데이트하는 옵션입니다. **마켓과는 아무런 관련이 없는 옵션입니다.**"*
> *"원문정보 상관없이 마켓에만 정보를 반영하시려면 본 옵션은 체크하지 마시기 바랍니다."*

🎯 **여기서 「크롤」과 「전송」이 명확히 분리된다.**
```
③ 업데이트 항목  = 소싱처 → 더망고   (크롤)
④ 마켓 선택      = 더망고 → 마켓     (전송)
```
둘 다 한 버튼으로 **순차 실행**. 항목 미선택 = 크롤 건너뛰고 전송만.

### ④ 마켓 선택 (체크박스 6개)
`#옥션2.0` `#G마켓2.0` `#11번가` `#스마트스토어` `#쿠팡` `#롯데ON`
> *"상품업데이트가 완료되면 선택하신 모든 마켓에 **동시에** 전송됩니다. (현재 더망고에 보여지는 상품정보가 **모두** 전송됩니다.)"*
> 🔴 *"**마켓 전송시에는 가격, 재고등 일부정보만 전송할 수 없습니다.**"*

🔴🔴 **결정적 열위**: 더망고는 **전 항목 전송만 가능**하다. 가격 하나 바뀌어도 상품 전체를 다시 올린다.
🔵 **우리는 옵션 단위 가격·재고만 보낸다** — `uploader/adapters/*.py::update_price_and_stock`(쿠팡·11번가·ESM·롯데온 전부 구현). **마켓 API 부하가 자릿수로 다르다.**
⇒ 앞서 「업로드 게이트」 우위라고 했는데, **그 아래에 더 근본적인 우위가 하나 더 있었다** — 우리는 *보낼 것만* 보낼 수 있다.
