### 🎯 부품 재사용 2곳 — 「불러오기」 드롭다운
- **`- 저장된 가격정책 불러오기 -`** (가격 섹션)
- **`- 저장된 마켓설정 불러오기 -`** (마켓 탭 안, 마켓마다 따로)

⇒ 정책 전체를 복사하지 않고 **가격 부분만 / 특정 마켓 설정만** 끌어다 쓸 수 있다.
⚠️ 그런데도 정책 목록에 `- 복사본`, `- 복사본 - 복사본`이 6개 이상 → **[선택설정복사등록] 버튼이 훨씬 편해서 실무는 통째 복사로 굴러간다.** 부품 재사용이 있어도 안 쓰이면 없는 것과 같다.
🟢 **우리 설계 교훈**: 재사용 단위를 만들되, **복사보다 쉬워야** 쓰인다.

⇒ **저가일수록 마진율 높게, 고가일수록 낮게.** 고가 상품은 절대금액이 크니 낮은 %로도 충분하고, 가격 경쟁력도 지킨다.
🟢 **채택**: 우리 「판매가 15칸」 템플릿과 겹치지만, **구간 경계를 사용자가 직접 정하는 표 UI**가 더 직관적.

### 🎯🎯 상품금액 계산식 — **화면에 공개돼 있다**
```
[상품금액] = [원가] + [마진금액] + [국제운송료] + [별도 추가요금] + [관세] + [부가세]

[원가]      = ( [상품가격] + [현지배송비] ) × [환율] − [할인금액]
[할인금액]  = [상품가격] × [환율] × [할인율]   또는  [할인금액]
[마진금액]  = [원가] × [마진율] 과 [최소마진금액] 중 높은 금액   또는  [마진금액]
[관세]      = ( [원가] + [국제운송료 또는 선편요금] ) × [관세율]
[부가세]    = ( [원가] + [국제운송료 또는 선편요금] + [관세] ) × 10%
[개별소비세] = ( [원가] + [국제운송료 또는 선편요금] − [개별소비세 적용기준금액] ) × [개별소비세율]
[교육세]    = [개별소비세] × [교육세율]
```

🔴 **우리와의 결정적 차이가 여기서 확정된다.**
- 더망고 `[상품가격]` = **소싱처 표면 판매가** (혜택 차감 없음)
- 모음전 원가 = **최종매입가** = 표면가 − 리뷰금 − N쇼핑/캐시백 − 카드청구할인·적립 (순차 곱셈 차감)

⇒ **더망고는 「얼마에 살 수 있나」를 모른다. 「얼마에 표시돼 있나」만 안다.**
우리 최종매입가 엔진([[project_bulk_register_phase1b_pricing_model]])은 더망고에 **대응물 자체가 없는 압도적 우위**다. 이걸 대량등록에 그대로 얹으면 같은 상품을 더 싸게 팔고도 더 남는다.

### 🎯 커스텀 가격계산 수식 — 사용자 작성 수식
> "가격계산 수식을 입력할 경우 **위의 가격계산설정은 모두 무시**되며, 입력한 수식으로만 상품가격을 계산합니다."
> - 변수: `{원가}` `{환율}`
> - 연산: 괄호 `( )` · 숫자 `0~9` · 곱하기 `*` · 더하기 `+` · 빼기 `-` **만**
> - 예시: `( ( {원가} * {환율} ) + 20000 -1000 ) * 1.08 * 1.1 * 1.2`

🟡 **판정 — 부분 채택.** 발상(사용자가 수식을 쓴다)은 좋지만 **「입력하면 위 설정 전부 무시」는 위험한 all-or-nothing**이다. 최소마진·역마진 가드까지 통째로 꺼진다.
⇒ 우리 방식(데이터 주도 혜택 항목 + `compute_breakdown`)이 안전. **우리가 채택할 것은 「수식을 화면에 보여주는 것」**이지 「수식으로 대체하는 것」이 아니다. 사장님이 계산 근거를 눈으로 확인할 수 있어야 한다(= fx영수증과 같은 철학).

#### 🎯 6. 배송비정책 — 매뉴얼보다 선택지가 많다
매뉴얼엔 무료/유료뿐이었으나 실제로는 **6종**:
무료배송 / 조건부 무료 / 유료 / **1개 수량별 차등** / **n개 수량별 차등** / **구간별 차등**
\+ 제주·도서 추가배송비 별도 칸

그리고 화면에 총액 고정 원리를 그대로 적어놨다 (매뉴얼 §117과 동일):
> 계산 총액 199,000 → 무료배송이면 `상품가 199,000 + 배송비 0` / 유료 3만이면 `상품가 169,000 + 배송비 30,000`
> *"유료배송비를 높게 조정하시면 **상품원금액이 낮게 보여질 수 있는 효과**가 있습니다."*

🟢 **채택 확정.** 검색 노출가 경쟁의 실전 기법. 우리 「표시가 vs 업로드가」([[project_pricing_display_vs_upload]])를 정책 항목으로 승격시키면 된다.
