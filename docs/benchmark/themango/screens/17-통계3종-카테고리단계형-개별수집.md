# ★★ 4. 개별수집 (`getGoods2.php`) — 🔴 규모의 진실

> **`※ 개별수집 무료사이트 : 756 개 / 신규사이트 2 개`**

**전 세계 소싱처 756곳.** 한국·미국·일본·중국·독일·프랑스·영국·이탈리아·스페인·캐나다·호주·홍콩·싱가포르·네덜란드·스웨덴·폴란드·튀르키예·뉴질랜드·덴마크·오스트리아…

일부에는 **`[재분석중]`** 표시 (= **파서가 깨져 수리 중**). 실측된 것만: ALDOShoes · atomyaza · belk · coggles · descente.co.jp · FashionNova · Giikmall · Greenweez · idus · MANGO.com · mavigadget · Maxaroma · Moosejaw · Nordstrom · NordstromRack · PXG · reebonz · remiinc · shopping.samsungcard · SPANX · StoneIsland · theYamazakiHome · ThirtyMall · UnderArmour.co.kr · Walgreens (**25곳 이상**)

## 🔴 이제 「소싱처 개수」의 진실이 완전히 정리된다
| 층 | 개수 | 뜻 |
|---|---|---|
| **개별수집 지원** | **756곳** | 상품 URL 1건씩 넣으면 긁힌다 |
| **대량수집 지원** | **4곳**(eBay·롯데ON·무신사·SSG) | 리스팅 URL 로 다건 |
| **사장님이 실제로 쓰는 곳** | **11곳** (§06 확정) | 상품이 저장돼 있고 정책이 걸려 있다 |
| 과거 이력만 남은 곳 | +2 (FOLDERStyle · SugarGirl) | |

### 🎯 여기서 배울 진짜
**756곳을 지원한다는 게 강점이 아니다.** `[재분석중]` 이 25곳 넘는다 — **소싱처가 화면을 바꾸면 파서가 깨지고, 그걸 고치는 데 시간이 걸린다.**
⇒ 🔵 **우리 방침이 옳다** — 소싱처를 **11곳으로 좁히고 각각을 정확하게** 유지하는 것. [[feedback_crawl_verification_protocol]]·[[feedback_stock_price_ground_truth_browser_url]] 의 「정답지=실브라우저 URL, 폴백 금지」가 이래서 필요하다.
⇒ 🟢 **다만 `[재분석중]` 표시는 채택** — 파서가 깨졌으면 **화면에 그렇게 적는다.** 조용히 빈 값을 주지 않는다. 우리 「확인불가」 원칙과 같다.

## 🎯 「개별수집 → 대량수집 승격」 버튼
> **`1A-Neuware.de 사이트를 대량수집 사이트로 세팅 (Pro 전용)`**

⇒ 개별수집만 되는 사이트를 **대량수집으로 올려달라고 요청**하는 기능.
⇒ 🟡 우리에겐 이런 계층이 없다(어댑터는 만들거나 안 만들거나). 다만 **「이 소싱처는 리스팅 수집이 되나?」를 화면에 표시**하는 건 필요하다.

## 개별수집 폼 = 대량수집과 **같은 세부저장조건**
`검색필터명` · `금지어 적용`(템플릿 7종) · `적용정책` · `적용카테고리` · `마켓검색태그` · `번역 후 저장` · `랜덤키워드 설정` · `옵션저장 조건`
⇒ **수집 경로가 달라도 저장 조건은 하나다.** 🟢 우리도 같게 — **「URL 1건」과 「리스팅 다건」이 같은 저장 조건 폼을 공유**한다.

## 곁다리 — 정책이 또 늘었다
§01 에서 138개였는데 새 이름이 보인다: `리바이스_타임` · `밀레_타임` · `이미스_타임` · **`탑텐`** · **`탑텐 배송비`** · **`탑텐_마켓`**
⇒ 오늘도 정책을 만들고 계신다. **정책 폭발이 진행 중**이라는 증거. §07 🟢5(마켓아이디 그룹)의 근거가 더 강해졌다.
