# 채택 게이트 — 「없다고 다 만들지 않는다」

> 사장님 지시(2026-08-06): *"우리 프로그램에 기능 없다고 더망고 있는 모든 기능을 흡수하고 싶지 않아.
> 굉장히 구조적으로 불편하고 안 좋은 것들도 있을 거야. 다만 좋은 것들을 우리 기능에 맞추어 추가해서
> 살을 붙이는 것이지, **불필요한 것들을 마구 쌓고 싶은 건 아니야.**"*

---

## 1. 내 판정 틀에 있던 구멍

§04 에서 🟢를 이렇게 정의했다:
> 🟢 **따라할 것** = Job 이 우리에게 **있고**, 우리 해법이 **없거나 열등**하다

**이건 필요조건일 뿐 충분조건이 아니다.** 이 기준만으로 판정하니 🟢가 **40개 넘게** 쌓였다.
그걸 다 만들면 결과는 **더망고를 하나 더 만드는 것**이다. 목표는 그게 아니다.

빠져 있던 질문은 이것이다 — **「그래서 이게 정말 좋은 기능인가?」**
더망고에 있는 기능 중 상당수는 **더망고 구조의 결함을 우회하려고 만든 것**이다. 우리에겐 그 결함이 없으므로 우회도 필요 없다.

## 2. 채택 게이트 5문 — 🟢 후보는 전부 통과해야 한다

| # | 질문 | 떨어지면 |
|---|---|---|

| **G2 대체** | 우리가 **이미 가진 부품**으로 같은 결과를 낼 수 있나? | 있으면 신규 기능 대신 **기존 것을 확장** → 🟡 |
| **G3 원인** | 더망고가 이걸 만든 이유가 **저쪽 구조 결함의 우회**는 아닌가? | 그렇다면 우리에겐 **문제 자체가 없다** → 🔴 |
| **G4 비용** | 화면·개념이 하나 늘면 **사장님과 팀이 배울 게 하나 는다.** 그만한 값어치인가? | 아니면 ⚪ 보류 |
| **G5 위험** | 잘못 쓰이면 어떤 사고가 나나? **선택지를 주는 것 자체가 위험**하진 않나? | 위험하면 **기본값 고정** → 🟡 |

### 판정을 4단으로 다시 나눈다
| | 뜻 |
|---|---|
| 🟢 **채택** | 5문 통과. 지금 만든다 |
| 🟡 **형태 바꿔 채택** | Job 은 취하되 **우리 방식**으로. 저쪽 UI 를 베끼지 않는다 |
| ⚪ **보류** | 필요해지면 그때. **지금 안 만든다** ← 새로 만든 칸 |

> ⚪ 는 「없다」가 아니라 **「알고 있고 지금은 안 만든다」**는 기록이다. 나중에 필요해지면 여기서 꺼낸다.

## 3. 전수 재판정 — 🟢 40+ → **13개**

### 🟢 채택 13 (핵심만)

#### A. 대량등록이 성립하려면 반드시 필요한 것 (5)
| # | 기능 | 왜 통과했나 |

| 2 | **신규상품수집(필터 재실행)** | G1 실사용 · **안 하면 팔 물건이 안 늘어난다** · 🔵 우리는 랩에 얹어 **자동**으로 (더망고는 사람이 눌러야 함) |
