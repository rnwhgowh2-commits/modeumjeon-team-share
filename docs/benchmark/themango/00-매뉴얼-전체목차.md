## 이 목차만으로 이미 드러난 것

1. **크롬 익스텐션으로 수집한다** — 우리와 같은 구조([[project_crawl_chrome_extension]]). 서버 크롤이 아님.
2. **AI가 3곳에 박혀 있다** — AI 마켓 카테고리 자동매핑 / 상품 스펙 AI 번역 / AI 이미지 편집기.
3. **「마켓분산등록」**이라는 개념이 별도 설정으로 존재 — 같은 상품을 여러 마켓·여러 계정에 흩어 등록.
4. **「업데이트 반복설정」**이 상품수집관련 설정에 있음 = 사장님 5단계 ⑤(가격·재고 지속 갱신)의 실체.
5. **「정산금액 계산식 설정」**이 마켓별로 있음 — 우리 수수료율 표와 대응.
6. **수집 제한 장치가 촘촘하다** — 금지어 / 가격제한 / 최대재고 / 품절상품 수집여부 / 옵션 수집 제외 / 수집제한 관리.
7. **해외 구매대행 전제** — 통관부호·배송대행지·환율·현지배송비·운송료. 우리는 국내 소싱이라 **이 축은 통째로 불필요**(도입 금지 후보).
