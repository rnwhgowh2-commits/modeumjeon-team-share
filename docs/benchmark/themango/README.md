## 2. 절대 잊으면 안 되는 것 6가지

### ① 🔴 이관(migration)이 예정돼 있다 — 설계의 전제
```
① 우리 대량등록 프로그램을 먼저 갖춘다   ← 지금
② 그 다음 더망고 자산을 옮긴다            ← 다른 세션
```
- 규모: **상품 168,291개** · 정책 138개+ · 검색필터 · 카테고리매핑
- 🔴 **성패 = 「소싱처URL ↔ 마켓상품번호」 짝 보존.** 못 옮기면 마켓 중복 등록 = 계정 위험
- 통로 판정: 엑셀 내보내기 ❌ / 더망고 API 🔴미구독·유료 / **마켓 API 직접 조회 🟢채택**
- 짝 열쇠 후보: **`판매자상품관리코드`** (더망고 엑셀 R컬럼 = 마켓 판매자상품코드)
- 받을 그릇은 **이미 있다**(재구현 금지): `MarketProduct` · `MarketProductGroup` · `BundleAccountRegistration` · `ProductDraftMarket(account_key)`

### ② 🔴 소싱처는 **11곳**만 (사장님 캡처로 확정)
`29CM` · `ABCmart.a-rt.com` · `FashionPlus` · `GrandStage.a-rt.com` · `GSShop` · `lotteimall` · `LOTTEON` · `MUSINSA` · `SSFShop` · `SSG` · `theHyundai`
**겹침 6 / 신규 5.** ABCmart·GrandStage 는 `a-rt.com` 동일 도메인 → 어댑터 한 벌.
※ 더망고는 개별수집 756곳을 지원하지만 **25곳 이상이 `[재분석중]`(파서 깨짐)**. 넓히는 게 강점이 아니다.

### ③ 🔴 「없다고 다 만들지 않는다」 — 채택 게이트 5문
G1 **사장님이 실제로 쓰나**(가장 강력) / G2 기존 부품으로 되나 / G3 **저쪽 구조결함의 우회 아닌가** / G4 배울 비용 값어치 / G5 잘못 쓰이면?
판정 4단: 🟢채택 / 🟡형태 바꿔 / **⚪보류(알고 있고 지금 안 만듦)** / 🔴안 함

### ④ 🔴 비교는 **이름이 아니라 Job(푸는 문제)** 기준
6칸 필수: Job / 우리에게 그 Job 있나 / 저쪽 해법 / **우리 해법(파일:줄 근거)** / 동일성 / 판정
🔴 **단방향 grep 은 거짓 음성이 보장된다** — 저쪽 단어로 우리 코드를 찾아 0건이면 「없음」으로 오판.
**양방향 필수**: 우리 **ORM 테이블 132개** 명부에서 시작해 「우리에게 있는데 저쪽엔?」도 묻는다.
🔴 **모음전 탭 + 대량등록 탭 둘 다** 뒤진다 — 최대 오판(정책 상속)이 한쪽만 봐서 났다.

### ⑤ 🔴 우리 진짜 숙제 (더망고와 무관)
> **정책 시스템이 두 벌이다.**
> 모음전 `MarketPolicy`+`MarketPolicyValue`+`BundlePolicyLink`+`SetPolicyLink`(상속·`from_common_at` 출처표시·`brand` 컬럼)
> ↔ 대량등록 `ProcessPolicy`+13항목(`PolicyConflict` 로 겹침 금지)
>
> 더망고는 **하나로 통합**돼 있다. 배울 진짜는 「상속 만들기」가 아니라 **「두 벌 합치기」**.

### ⑥ 🔴 실측 규율 (이번에 아프게 배움)
- **스크린샷 OCR 로 숫자·컬럼명 읽고 결론 내지 말 것** — 「휴지통」을 「유지율」로 오독해 *"78~100%가 죽는다"*는 정반대 결론을 냈고 메모리에까지 저장했다. **`get_page_text` 로 재확인**
- **화면 하나만 보고 개수를 단정하지 말 것** — 소싱처를 4→10→13→11 로 **네 번** 고쳤다
- **「없다」 판정에는 근거를 단다** — `grep 0건`은 근거가 아니다

## 3. 🟡 사장님 판단 대기 — **6건** (다음 세션 첫 할 일)

| # | 항목 | 판단 자료 |

| 3 | **마켓 전송 재고 고정값** | 사장님 현재 **10개**. 우리도 10? (⚠️상한이지 하한 아님 — 0은 0으로) |
| 4 | **랜덤키워드**(상품명 마침표) | 이미 사용 중. 마켓 어뷰징 저촉 여지 |
| 5 | **마켓분산등록** | 지금은 등록 한도 미도달 |
| 6 | **더망고 API 유료 신청** | 이관용. `Call 차감` 과금 vs 마켓 API 우회 |

### 🔴 확인 과제 1건 (실전송 전 필수)
**11번가·롯데ON 카테고리 국내/해외 구분** — 우리 `MarketCategory`(`registration/models.py:167`)에 구분 컬럼이 없고 수집기는 한 벌만 가져온다.
틀리면 **마켓에서 카테고리 변경 불가 → 삭제 후 재등록만이 복구.** 대량이면 수천 건이 한 번에 잘못 나간다.
